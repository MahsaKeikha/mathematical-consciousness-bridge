# Repository scripts

This directory contains the executable support scripts used to reproduce, validate, and maintain the Mathematical Consciousness Bridge repository.

## Primary commands

From the repository root:

```bash
python scripts/generate_all_figures.py
python scripts/generate_all_figures.py --validate-only
python scripts/verify_repository.py
```

These commands are also exposed through the root `Makefile` as `make figures`, `make figures-check`, and `make verify`.

## Figure generation

### `generate_all_figures.py`

Canonical entry point for figure reproducibility. It runs the computational atlas generators and then validates the complete SVG tree under `docs/figures/`.

### `generate_quantitative_atlas.py`

Generates the quantitative physics and mathematics atlas under:

```text
docs/figures/quantitative/
```

The output includes SVG figures plus `quantitative_figure_manifest.json`.

### `generate_quantum_foundations_atlas.py`

Generates the quantum-foundations atlas under:

```text
docs/figures/quantum/
```

The output includes SVG figures plus `quantum_figure_manifest.json`.

## Figure documentation support

### `conceptual_figure_records.py`

Structured records for source-controlled conceptual and theorem figures.

### `quantum_figure_records.py`

Structured documentation records for the quantum visual material.

### `enrich_figure_documentation.py`

Maintenance utility for enriching figure-documentation surfaces from the structured figure records.

## Repository verification

### `verify_repository.py`

Network-free repository consistency checker. It verifies the current release/frontier markers, proposition-file coverage, principal local documentation links, source/test presence, and active test/figure workflows.

This complements `pytest`; it does not replace the theorem and regression tests.

## Typography maintenance

### `normalize_typography.py`

Repository maintenance utility for enforcing the public-text typography policy used by the test suite.

## Scientific provenance rule

Not every SVG in `docs/figures/` is generated by a plotting script.

- `docs/figures/quantitative/` and `docs/figures/quantum/` are computationally generated atlases.
- theorem, architecture, dependency, and explanatory SVGs stored directly in `docs/figures/` are source-controlled publication diagrams.

The unified figure command regenerates the computational atlases and validates the complete SVG tree so these two provenance classes remain explicit rather than being conflated.

For complete setup and execution instructions, see [`docs/reproducibility.md`](../docs/reproducibility.md).
