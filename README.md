**Mahsa Keikha, PhD**

> **What would have to be true for a mathematical and physical description of a system to justify a scientifically meaningful claim about consciousness?**

This repository develops a formal mathematical-physics program for the **consciousness bridge problem**: the problem of connecting physical organization to formal experiential structure through explicit bridge principles, theorem-level consequences, empirical identifiability, falsification, and finite-data certification.

The program builds on, but remains logically distinct from, [Spatiotemporal Observer Mathematics](https://github.com/MahsaKeikha/spatiotemporal-observer-math), which studies whether a persistent moving subsystem can be inferred and certified from dynamics. That companion project can supply a candidate physical subsystem. The present project studies the additional bridge required before a claim about consciousness is justified.

---

# Abstract

A physical theory can specify states, dynamics, interventions, and observable laws without specifying why any physical organization should correspond to subjective experience. A mathematical consciousness theory therefore requires an additional object: a bridge from physically meaningful equivalence classes to formal experiential equivalence classes.

This repository makes that bridge itself the object of mathematics. It begins by defining the physical domain, experiential domain, representation equivalences, admissible experiment classes, and observable laws generated by complete bridge theories. It then proves representation-invariance conditions, introduces an experiment-class discriminability based on total-variation distance, proves an exact statistical non-identifiability criterion, and quotients the theory space into observational bridge-equivalence classes. These results establish both constructive requirements and no-go conditions that any eventual universal consciousness theorem must respect.

The long-term target is not a renamed complexity score. It is a theorem-and-evidence package in which:

\[
\boxed{
\text{physical first principles}
+
\text{bridge principles}
+
\text{empirically validated discriminants}
\Longrightarrow
\text{formal experiential property}.
}
\]

The implication must be proved mathematically, while the bridge premises must be exposed independently to empirical failure.

# 1. The scientific problem

The core logical chain is

```text
physical realization
        |
        v
physical equivalence class
        |
        v
mathematical bridge
        |
        v
experiential equivalence class
        |
        v
observable predictions
        |
        v
empirical discrimination / falsification
```

Mathematically,

\[
\boxed{
\text{physical system}
\longrightarrow
\text{mathematical structure}
\longrightarrow
\text{bridge principles}
\longrightarrow
\text{consciousness claim}.
}
\]

The central challenge is the third arrow.

A theorem about integration, complexity, recurrence, global broadcasting, causal structure, or subsystem persistence does not automatically become a theorem about consciousness. The project therefore treats the bridge as an explicit scientific object rather than hiding it inside a definition.

# 2. Physical foundation

A physical input is modeled abstractly as

\[
\boxed{
p=(\mathcal X,\mathcal D,\mathfrak I,\mathcal O),
}
\]

where:

| Object | Physical role |
| --- | --- |
| \(\mathcal X\) | state space |
| \(\mathcal D\) | deterministic or stochastic dynamics |
| \(\mathfrak I\) | admissible intervention class |
| \(\mathcal O\) | observable/measurement map |

A deterministic continuous-time realization may have

\[
\dot x(t)=F(x(t),u(t)),
\qquad
 y(t)=h(x(t)),
\]

while a stochastic realization may have

\[
dX_t=f(X_t,u_t)\,dt+G(X_t,u_t)\,dW_t,
\]

or transition kernel

\[
X_{t+\Delta t}
\sim
K_{\Delta t}(\cdot\mid X_t,u_t).
\]

The bridge must state which level of physical description is primitive and which interventions count as physically admissible.

## 2.1 Physical representation equivalence

The same physical process can be written in many coordinate systems. For an invertible reparameterization

\[
z=\varphi(x),
\]

the transformed dynamics are

\[
\dot z
=
D\varphi(x)F(x,u),
\qquad
x=\varphi^{-1}(z).
\]

If this is only a change of representation, the consciousness assignment should not change.

We therefore introduce a physical equivalence relation

\[
\boxed{
p\sim_P p'.}
\]

The physically meaningful bridge input is the quotient class

\[
\boxed{
[p]_{\sim_P}\in\mathcal Q_P,
\qquad
\mathcal Q_P=\mathcal P/{\sim_P}.
}
\]

# 3. Experiential domain

Let

\[
\mathcal E
\]

be a formal space of candidate experiential structures, and let

\[
e\sim_E e'
\]

mean that two mathematical descriptions represent the same experiential structure for the purposes of the theory.

The experiential quotient is

\[
\boxed{
\mathcal Q_E=\mathcal E/{\sim_E}.
}
\]

Defining \(\mathcal Q_E\) rigorously is one of the central unresolved stages of the program. The project will not assume that a convenient mathematical representation is automatically a faithful representation of phenomenology.

Work by Kleiner and by Kleiner and Tull is important here because it makes the mathematical representation of experience itself part of the formal problem rather than an invisible assumption.

# 4. The consciousness bridge

The most general starting point is a relation

\[
\boxed{
\mathcal B\subseteq\mathcal P\times\mathcal E.
}
\]

When single-valuedness and equivalence invariance are justified, the desired quotient-level object becomes

\[
\boxed{
\bar B:
\mathcal Q_P
\longrightarrow
\mathcal Q_E.
}
\]

A complete empirical bridge theory contains more than \(\bar B\). It must also specify how physical states, bridge principles, measurement models, and experimental protocols induce observable probability laws.

A useful abstract theory tuple is

\[
\boxed{
\mathfrak T=
(\mathcal P,\mathcal E,\sim_P,\sim_E,\mathcal B,\mathcal M,\Pi),
}
\]

where \(\mathcal M\) is the measurement interface and \(\Pi\) is the admissible experiment class.

A result is not treated as approaching a universal consciousness theorem unless it addresses all of the following layers.

| Criterion | Requirement |
| --- | --- |
| U1 | physical well-definedness |
| U2 | experiential well-definedness |
| U3 | non-definitional bridge |
| U4 | representation invariance |
| U5 | empirical identifiability |
| U6 | cross-theory discrimination |
| U7 | temporal and compositional consistency |
| U8 | substrate generality |
| U9 | finite-measurement certification |
| U10 | falsification exposure |

The strongest target has schematic form

\[
\boxed{
\begin{aligned}
& p\in\mathcal Q_P,\\
& A_1,\ldots,A_k\text{ bridge principles hold},\\
& F_1(p),\ldots,F_m(p)\text{ certified physical properties hold},\\
& V_1,\ldots,V_r\text{ empirical validation conditions hold}
\\[2mm]
&\qquad\Longrightarrow
\bar B(p)\in\mathcal C_E,
\end{aligned}
}
\]

where \(\mathcal C_E\subseteq\mathcal Q_E\) is a formally specified class of conscious experiential structures.

A still stronger biconditional target is

\[
\boxed{
\bar B(p)\in\mathcal C_E
\iff
\mathcal F(p)\in\mathcal R_C,
}
\]

but both directions would require independent justification.

# 7. Proposition 1: representation invariance

Let

\[
B:\mathcal P\to\mathcal Q_E
\]

be a candidate bridge assignment and let

\[
\pi_P:\mathcal P\to\mathcal Q_P
\]

be the physical quotient projection.

## Proposition 1

There exists a unique map

\[
\boxed{
\bar B:\mathcal Q_P\to\mathcal Q_E
}
\]

satisfying

\[
B=\bar B\circ\pi_P
\]

if and only if

\[
\boxed{
p\sim_Pp'
\Longrightarrow
B(p)=B(p').
}
\]

This is the exact condition required for a consciousness assignment to be independent of physically irrelevant changes of representation.

**Status:** proved.

[Full statement and proof](docs/proposition_1_representation_invariance.md)

# 8. Proposition 2: experiment-class bridge identifiability

Fix a physical equivalence class

\[
q\in\mathcal Q_P
\]

and an admissible experiment class \(\Pi\).

For a complete theory \(\mathfrak T_i\), protocol \(\pi\), and physical input \(q\), write

\[
P_i^{\pi,q}
\]

for the predicted observable probability law.

Define total-variation distance

\[
\boxed{
\|P-Q\|_{\mathrm{TV}}
=
\sup_A|P(A)-Q(A)|.
}
\]

The experiment-class discriminability is

\[
\boxed{
\Delta_\Pi(\mathfrak T_1,\mathfrak T_2;q)
=
\sup_{\pi\in\Pi}
\|P_1^{\pi,q}-P_2^{\pi,q}\|_{\mathrm{TV}}.
}
\]

## Proposition 2A: exact non-identifiability

\[
\boxed{
\Delta_\Pi=0
\iff
P_1^{\pi,q}=P_2^{\pi,q}
\quad\text{for every }\pi\in\Pi.
}
\]

## Proposition 2B: optimal one-shot discrimination

With equal prior probability on the two theories, the optimal one-shot error under protocol \(\pi\) is

\[
\boxed{
R_\pi^*
=
\frac12
\left(
1-
\|P_1^{\pi,q}-P_2^{\pi,q}\|_{\mathrm{TV}}
\right).
}
\]

Optimizing over \(\Pi\),

\[
\boxed{
\inf_{\pi\in\Pi}R_\pi^*
=
\frac12(1-\Delta_\Pi).
}
\]

Thus a disagreement about consciousness assignments is not yet an empirical disagreement. It becomes scientifically distinguishable only when the bridge difference changes an observable law under at least one admissible experiment.

## Proposition 2C: repeated discrimination

If a discriminating protocol is independently repeatable and an event has probability gap \(\eta>0\), then the event-frequency test satisfies

\[
\boxed{
P(\mathrm{error})
<
\exp\left(-\frac{n\eta^2}{2}\right).
}
\]

The proof uses Hoeffding concentration.

**Status:** proved.

[Full statement and proof](docs/proposition_2_bridge_identifiability.md)

# 9. Proposition 3: observational bridge-equivalence classes

For a family of complete bridge theories \(\Theta\), define the full observable fingerprint

\[
\boxed{
\Phi_{\Pi,q}(\mathfrak T)
=
\left(P_{\mathfrak T}^{\pi,q}\right)_{\pi\in\Pi}.
}
\]

Define

\[
\boxed{
\mathfrak T_1\sim_{\Pi,q}\mathfrak T_2
}
\]

when

\[
P_{\mathfrak T_1}^{\pi,q}
=
P_{\mathfrak T_2}^{\pi,q}
\quad
\text{for every }\pi\in\Pi.
\]

Equivalently, by Proposition 2,

\[
\Delta_\Pi(\mathfrak T_1,\mathfrak T_2;q)=0.
\]

## Proposition 3A

The relation \(\sim_{\Pi,q}\) is an equivalence relation on \(\Theta\).

Therefore

\[
\boxed{
\Theta/{\sim_{\Pi,q}}
}
\]

is well defined.

## Proposition 3B

Each equivalence class is exactly a fiber of the observational fingerprint:

\[
\boxed{
[\mathfrak T]_{\Pi,q}
=
\Phi_{\Pi,q}^{-1}
\left(\Phi_{\Pi,q}(\mathfrak T)\right).
}
\]

## Proposition 3C

The quotient theory space is in bijection with the image of the fingerprint map:

\[
\boxed{
\Theta/{\sim_{\Pi,q}}
\cong
\operatorname{Im}(\Phi_{\Pi,q}).
}
\]

This yields a direct no-go result:

> If two bridge theories belong to the same observational equivalence class, no statistical method using only data from the declared experiment class can identify which individual theory is correct, because their data-generating laws are identical.

A richer experiment class can split an equivalence class but cannot merge theories that were already distinguishable under a smaller class.

**Status:** proved.

[Full statement and proof](docs/proposition_3_bridge_equivalence_classes.md)

# 12. Evidence and claim hierarchy

Every statement should carry one of the following statuses.

| Status | Meaning |
| --- | --- |
| **Definition** | mathematical object introduced by the framework |
| **Candidate bridge principle** | substantive bridge hypothesis under investigation |
| **Proved** | theorem derived from explicit assumptions |
| **Identifiability result** | theorem about what observations can or cannot resolve |
| **Empirical result** | claim supported by a stated experiment and dataset |
| **Falsified under model** | a declared prediction rejected under stated assumptions |
| **Open** | unresolved mathematical or empirical question |

This distinction is central to the project. A proof internal to a bridge theory is not automatically empirical evidence that the bridge premise is true.

# 13. Falsification program

A candidate bridge is exposed to at least four classes of failure.

## 13.1 Representation failure

Physically equivalent descriptions receive nonequivalent experiential assignments.

## 13.2 Identifiability failure

The bridge asserts a physical distinction while every admissible experiment produces the same observable law, without acknowledging underdetermination.

## 13.3 Composition or temporal failure

Subsystem, composite, or time-continuation assignments contradict the theory's own bridge laws.

## 13.4 Prediction failure

A bridge-dependent empirical prediction is rejected under a preregistered or otherwise explicitly declared protocol.

See the full [Falsification Program](docs/falsification_program.md).

# 17. Immediate frontier

The next theorem is **Proposition 4: optimal discriminating experiment design**.

The goal is to turn theory comparison into an experiment-design problem. For a protocol \(\pi\), candidate theory family \(\Theta\), and pairwise total-variation separation, the first target functional is

\[
\boxed{
U(\pi)
=
\min_{
\mathfrak T_i\not\sim_{\Pi,q}\mathfrak T_j
}
\left\|
P_i^{\pi,q}-P_j^{\pi,q}
\right\|_{\mathrm{TV}}.
}
\]

A maximin discriminating protocol would satisfy

\[
\boxed{
\pi^*
\in
\arg\max_{\pi\in\Pi} U(\pi).
}
\]

For theory families that no single protocol can separate, the project will study minimal protocol sets that split every observational equivalence class.

That is the next step toward a bridge theory whose distinguishing claims are not only mathematically explicit but experimentally actionable.
