A five minute introduction

What would it take to connect a physical description to experience scientifically?

The project does not begin by choosing a formula for consciousness. It begins by asking what a serious scientific claim would have to demonstrate before we should trust it.

Follow the four steps See the Research Map Back to the overview

The basic logic

Four steps make the question testable

Each step protects the research from a different kind of confusion.

Step 1

Describe the physical system clearly

State what physical information is being used, including variables, dynamics, measurements, interventions, time, scale, and system boundaries.

Step 2

Keep the target independent

Do not create an experience related target from the same physical quantity and then use that target as evidence that the quantity explains it.

Step 3

Test the measurement and the model

Ask whether the target can be observed reliably and whether the proposed model makes restrictions that real data could violate.

Step 4

Ask whether the result survives uncertainty

Finite data, noisy observations, repeated searches, and numerical approximation should all be included before a conclusion is treated as evidence.

What the project has built

A chain of tests rather than one grand equation

The repository develops mathematical and computational tools for physical description, sufficiency, target integrity, measurement, model testing, finite data reasoning, and reproducibility.

These pieces are connected, but they do not all answer the same question. A result at one layer does not automatically prove the next layer.

The public theorem frontier is P87. The formal release is v0.82.0. The final physical to experiential bridge remains open.

The most important distinction

A physical model can be useful without being complete.

A statistical model can be rejected without proving which alternative is correct.

A latent variable can be mathematically useful without being consciousness.

The repository keeps these distinctions visible at every deeper layer.

Scientific boundary

This is a test framework, not a declaration that consciousness has been solved

The project asks what evidence would be needed for stronger claims and builds tools that can expose inadequate ones. It does not identify a particular hidden state, equation, field, or information measure as consciousness.
