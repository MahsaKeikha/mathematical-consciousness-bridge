A five minute introduction

What would it take to connect a physical description to experience scientifically?

The project does not begin by choosing a formula for consciousness. It begins by asking what a serious scientific claim would have to demonstrate before we should trust it.

Follow the four steps See the Research Map Explore all 87 results

The basic logic

Four obligations make the question testable

Each obligation protects the research from a different kind of confusion.

Physical description

Declare the physical system clearly

State what physical information is being used, including variables, dynamics, observations, interventions, time, scale, and system boundaries.

Target integrity

Keep the target independent

Do not construct an experience-related target from the same descriptor and then use it as evidence that the descriptor explains that target.

Model testing

Test the measurement and the model

Ask whether the target can be observed reliably and whether the declared model makes restrictions that real data could violate.

Uncertainty

Protect the conclusion

Finite data, adaptive searches, repeated looks, and numerical approximation should all be included before a mismatch is treated as evidence.

The most important distinction

A physical model can be useful without being complete.

A statistical model can be rejected without proving which alternative is correct.

A latent variable can be mathematically useful without being consciousness.

The public site keeps those distinctions visible at every depth.
