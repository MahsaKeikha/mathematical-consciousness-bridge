First-reader guide

From the simple question to the actual mathematics

This page is the bridge between the public explanation and the formal research. The project asks what must be true before a physical description can support a scientifically testable claim about an independently specified experiential target. It does not assume a formula for consciousness. It builds mathematical tests for the assumptions that such a claim would have to survive.

First principle

The project is not trying to guess a consciousness equation

It is building the scientific conditions that any proposed physical-to-experiential equation, model, or theory would have to satisfy before its success could be interpreted as evidence.

Physical description

State exactly what information is being used

Which variables, interactions, interventions, time scales, spatial scales, and system boundaries are included? A claim cannot be stronger than the information it actually uses.

Independent target

Do not build the answer into the evidence

An experience-related target cannot simply be manufactured from the same physical descriptor and then used as independent evidence that the descriptor explains it.

Measurement

Ask whether the target can actually be observed reliably

Reports, behavior, labels, and other target measurements can be noisy, incomplete, or systematically misleading. The measurement process is part of the scientific problem.

Model adequacy

Parameter recovery is not model validation

A model can estimate hidden quantities and still be wrong. The framework therefore creates independent constraints that can reject the declared model.

Finite data

Separate real incompatibility from sampling noise

A visible mismatch is not enough. The evidence must remain after finite-sample uncertainty and numerical certification are included.

Final bridge

Keep the unsolved step visible

Even perfect physical modeling and perfect statistics do not automatically identify experience. The final bridge principle must still be independently formulated and tested.

The most important boundary

This repository does not claim that consciousness has been derived from physics. A theorem about a declared model is not automatically a theorem about consciousness, a latent variable is not automatically experience, a failed descriptor is not proof of nonphysical consciousness, and failure to reject a model is not model validation.

The formal question

What does “physically sufficient” mean here?

At the deterministic level, the project asks whether an independently specified target \(E\) can be determined entirely from a declared physical descriptor \(T\):

\[E=B\circ T.\]

At the stochastic level, the analogous question is whether any target information remains once the physical descriptor is known:

\[I(E;\Omega\mid T)=0.\]

These are not definitions of consciousness. They are mathematical sufficiency conditions for a declared descriptor and a declared target under explicit assumptions.

Plain-language interpretation

If two cases have the same declared physical description but the independently defined target still distinguishes them, then that physical description is not sufficient for that target.

The scientifically correct next question is then what the description omitted or which assumption failed.

Current certified frontier

P78-P84 progressively tighten global separation from the declared continuous model family

P78 introduced exact-rational branch-and-bound for the continuous P75 target-measurement family. P79 certified the sampling-radius direction. P80 retained probability normalization. P81 added projected-event constraints. P82 added exact nested residual contrasts. P83 now adds 22 exact projection-parity observables that can expose dependency incompatibilities invisible to the complete P82 audit.

P84 now preserves shared-parameter compatibility between pairs of P83 parity events. Its 220 exact joint contrasts can reject a P75 box even when every individual P83 parity interval is compatible; the strict exact-rational witness has L83 = 0 and L84 = 1/32.

The important logical direction is one-sided. These results can strengthen rejection of the declared P75 model family. They do not identify a latent state with consciousness, do not validate the model when rejection fails, and do not close the physical-to-experiential bridge.

Scientific interpretation

Five things the repository deliberately refuses to overclaim

01

Descriptor failure is local

If one physical descriptor is insufficient, relevant physical information may have been omitted. This is not proof of nonphysical consciousness.

02

Good fit is not a bridge

A fit may be circular, underidentified, noisy, underconstrained, or compatible with many alternative models. Additional scientific obligations remain.

03

Latent is not experiential

A latent statistical state does not inherit experiential meaning without an independent semantic and empirical anchor.

04

Quantum is not enough by itself

A complete quantum description remains a physical description. A bridge principle still has to be stated and tested.

05

Non-rejection is inconclusive

Failure to certify incompatibility is not model acceptance and does not establish a physical-to-experiential bridge.
