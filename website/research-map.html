Six questions organize the whole program

The repository contains many formal results, but the scientific story is much simpler. Each part of the research answers one of six questions, and each question leads naturally to the next.

The scientific story

Follow the questions, not the proposition numbers

The proposition numbers record how the work developed. This map shows how a reader can understand the research.

Chapter 1

What physical system are we talking about?

Before asking whether physics explains anything, we need to know what the physical description actually contains, how the system changes, and which descriptions count as equivalent.

Explore the physical foundation

Chapter 2

Is the physical description actually enough?

A description can be useful and still leave something out. This part asks whether two cases that look identical physically could still differ according to the independent target.

Read the bridge problem

Chapter 3

Is the target genuinely independent?

If the target is created from the same physical information being tested, the reasoning can become circular. The target and its measurement need their own scientific justification.

Explore target integrity

Chapter 4

Can the proposed model be wrong?

A model becomes scientifically informative when observations can challenge it. This part develops tests that can expose incompatibility instead of only fitting parameters.

Explore falsification

Chapter 5

Does the conclusion survive uncertainty?

Real evidence comes with sampling noise, numerical approximation, and choices made during analysis. The research asks whether the conclusion remains justified after those uncertainties are included.

Explore verification and reproducibility

Chapter 6

What remains open?

Even a strong rejection of one model does not tell us automatically what consciousness is. The final connection from physical description to experience remains a separate scientific problem.

See the scientific boundary

How the pieces connect

Each question protects the next one

If the physical description is unclear, a sufficiency test is unclear. If the target is circular, the test cannot provide independent evidence. If the model cannot fail, a good fit proves too little. If uncertainty is ignored, an apparent discovery may not survive replication.

The research therefore develops the bridge in layers rather than trying to jump directly to one final equation.

Where the current frontier sits

P87 belongs to the model testing chapter

P87 strengthens a declared family of exact model separation tests. Its role is methodological: it asks whether a richer set of shared parameter constraints can reveal incompatibility that weaker checks miss.

What P87 does not establish: it does not identify a latent state with consciousness, prove that consciousness is nonphysical, or complete the physical to experiential bridge.

Read P87 only if you want the theorem level detail

The open question

What would finally justify the bridge?

A completed bridge would need more than a physical correlate and more than a successful statistical model. It would need a clearly justified connection between the physical description and the experiential distinction, together with evidence strong enough to test that connection.

This repository is building the structure needed to ask that question more precisely. It does not pretend the final answer is already known.
