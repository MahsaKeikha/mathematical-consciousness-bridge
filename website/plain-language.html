Think of a physical description as a map

A map can be extremely accurate and still leave out information that matters for a particular question. This research asks when a physical description is detailed enough for an experience-related claim, and how we could tell when it is not.

The simplest analogy

A good map is not a complete description of everything

A subway map can be excellent for navigation while saying almost nothing about temperature, architecture, or what someone is experiencing.

A physical model can work in the same way. It can predict many observations and still be too coarse for a different question.

The scientific question is whether the chosen description contains all the distinctions needed for the claim we want to test.

The key test

Imagine two situations that look identical according to the declared physical description.

If an independently justified target still distinguishes them, then that description is not sufficient for that target.

That tells us where a stronger explanation is needed. It does not automatically tell us what the missing explanation is.

Four obligations

The bridge claim must survive more than correlation

Physical side

What information is in the description?

State the variables, dynamics, observations, interventions, time, scale, and system boundary.

Target side

What distinction are we asking it to explain?

Define the target independently enough that agreement is meaningful rather than automatic.

Measurement side

Can we observe that target reliably?

Reports, behavior, labels, and other measurements may be noisy, incomplete, or systematically biased.

Model side

Can the explanation fail?

A useful scientific model should make restrictions that real observations could violate.

What the mathematics is for

To make the claim sharper, not more mysterious

The mathematics specifies equivalence, sufficiency, identifiability, finite-data uncertainty, model incompatibility, and certified numerical bounds.

The point is to make claims easier to test, easier to audit, and easier to reject when the evidence does not support them.

Scientific boundary

What the current frontier does and does not establish

P87 is a conditional model-separation result for the declared P75 target-measurement family. It does not identify a latent state with consciousness, prove that consciousness is nonphysical, or complete the physical-to-experiential bridge. The final bridge remains open.
