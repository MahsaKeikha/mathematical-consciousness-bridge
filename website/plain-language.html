The 60-second version

A complete physical description and a claim about experience are not automatically the same thing.

Science can measure a great deal about a physical system: electrical activity, chemistry, behavior, responses to stimulation, information flow, causal influence, and physical dynamics. Those descriptions can be extraordinarily powerful.

But a powerful description can still omit information needed for a particular question. To connect a physical description to an experience-related target scientifically, we need to know what physical information is included, how the target was defined, how it was measured, whether the model can fail, and whether the evidence survives finite-data uncertainty.

This project builds mathematics for making those obligations explicit rather than hiding them inside a favored theory.

One sentence

We are building tests for whether a proposed physical description is actually sufficient for an independently defined experience-related claim.

A simple analogy

Think of a physical description as a map.

A subway map can be excellent for finding a route and useless for telling you the height of a building. The map is not wrong. It simply was not designed to contain that information.

A physical model can have the same problem. It may predict behavior or measurements extremely well while still losing a distinction required by a particular target.

So one basic question is: if two situations look identical according to the physical description we chose, can an independently justified target still distinguish them? If yes, that physical description is not sufficient for that target.

What failure would mean

It would show that the declared description is insufficient for the declared target.

It would not prove that consciousness is outside physics. The descriptor may simply omit relevant physical information.

The research questions in ordinary language

Six questions keep the logic honest.

Each question guards against a different way of mistaking an attractive result for a stronger conclusion than the evidence supports.

01

What system are we describing?

Define the variables, dynamics, boundaries, interventions, time scales, and spatial scales actually included.

02

What target are we testing?

The target must be justified independently rather than constructed from the same descriptor being tested.

03

Can the target be measured reliably?

Reports, labels, behavior, and other observations can be noisy, incomplete, or unable to preserve the distinction we care about.

04

Does the model itself fit the observations?

Recovering hidden parameters does not prove that the model generating those parameters is correct.

05

Is the evidence stronger than finite-data uncertainty?

Statistical and numerical uncertainty must be included before an apparent mismatch becomes a certified rejection.

06

What would finally connect physics to experience?

That bridge remains open and requires independent formulation and empirical support beyond the earlier mathematical safeguards.

A different research posture

Do not start by declaring one quantity to be consciousness.

The project does not assume that consciousness is a neural pattern, information score, complexity measure, field, quantum effect, latent variable, or new dimension. Any of those could appear inside a proposed theory, but the proposal still has to survive the same scientific obligations.

How to interpret an outcome

Pass, fail, and inconclusive are different scientific statements.

Descriptor fails

This physical description is insufficient for this target.

The result does not say that every possible physical description must fail.

Model rejected

The declared model is incompatible under its assumptions.

That narrows the space of acceptable explanations without creating a metaphysical conclusion.

Not rejected

The result may simply be inconclusive.

Compatibility with available data is not proof that the model is true or unique.

All earlier checks pass

The bridge still has to be justified.

Good physics, measurement, and statistics create conditions for a serious bridge test; they do not automatically supply the bridge.

What the 88 results are doing

The theorem program builds the test architecture piece by piece.

P1-P18

Make the physical description defensible

Invariance, identifiability, causal structure, time, composition, and scale.

P19-P24

Test physical sufficiency

Ask whether the descriptor loses a distinction present in an independent target.

P25-P70

Make the tests operational

Scale compatibility, quantum formulations, experiment design, sequential evidence, and calibration.

P71-P74

Protect the target side

Target provenance, measurement robustness, identifiability, and finite-data recovery.

P75-P87

Test model adequacy

Move from overidentifying checks to exact continuous-family and dependency-aware separation certificates.

P88

Validate a selected result on fresh data

Freeze the discovery-selected box and functional before independent validation.

Current theorem frontier · P88

Can a discovery-selected incompatibility survive fresh data?

P88 allows discovery to search for a useful P75 box/P87 functional pair, then requires that pair to be frozen before an independent validation sample is examined. For the stored exact witness, the P79-certified minimum held-out sample size for the specified gap is 1063.

Boundary: the certificate is box-specific unless a separate global covering argument is supplied. It does not identify the latent state with consciousness or close the physical-to-experiential bridge.
