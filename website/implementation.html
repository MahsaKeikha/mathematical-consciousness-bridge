What reproducibility protects

Code does not decide what the science means

The theorem page defines the object, assumptions, and permitted conclusion first. The implementation is checked against that fixed target, rather than interpreting whatever the program happens to output.

Numerical estimates are distinguished from certified bounds, and successful execution is distinguished from empirical validation.
