Implementation guide

How the research actually works

This page connects the conceptual research map to the repository that executes and audits it. Each stage shows the scientific question, the computational transformation, representative source modules, and the proof/test/reproducibility surfaces a reader can inspect directly.

Important scientific boundary: executable mathematics is not evidence that the physical-to-experiential bridge has been solved. The code implements declared mathematical objects, tests, bounds, optimization procedures, and falsification criteria under stated assumptions. The bridge target remains open.
