Open research in mathematical physics and scientific inference

When is a physical description enough to support a claim about experience?

This project builds a testable research architecture for that question. It asks what must be described, measured, challenged, and verified before a proposed connection between physics and experience deserves scientific confidence.

The project in one minute

One research program, ten ordered branches

The public website follows the same branch names and the same proposition order everywhere. Proposition numbers record the formal result sequence; branch labels explain what each part of that sequence is doing scientifically.

P1-P18

Start with invariance, identifiability, recovery, interventions, time, composition, and scale-aware physical structure.

P19-P44

Move through the candidate bridge class, operational scale, and quantum interface without treating physical completeness as experiential completeness.

P71-P87

Protect the target and test the model

Separate target provenance from measurement, recover channels where possible, and test whether the declared target-measurement model can actually reproduce the data.

Why this is interesting

Correlation is not yet explanation

A physical description can be rich, predictive, and useful without automatically containing every distinction needed for an experience-related claim.

The research therefore separates physical description, target definition, measurement, model adequacy, uncertainty, and reproducibility instead of compressing them into one grand equation.

A simple way to picture the problem

Think of a physical description as a map. A map can be excellent for one purpose while leaving out information needed for another.

The scientific question is whether the chosen map contains enough information for the particular claim being tested.

Scientific boundary

What the current frontier does and does not establish

P87 is a conditional model-separation result for the declared P75 target-measurement family. It does not identify a latent state with consciousness, prove that consciousness is nonphysical, or complete the physical-to-experiential bridge. The final bridge remains open.
