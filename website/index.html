A testable framework for the physical-to-experiential bridge problem

This project asks what mathematical and physical conditions would be required before a complete physical description could support a scientifically testable claim about consciousness. It does not begin by assuming what consciousness is. The current target-side frontier separates target provenance, noisy observation, and the identifiability of the measurement stability used in the bridge test.

Scientific boundary

The repository does not claim that consciousness has already been derived from physics, that consciousness is necessarily quantum, that consciousness is a new dimension of spacetime, or that any familiar scalar quantity is identical to experience. Those hypotheses require independent mathematical derivation and empirical support.

The current standard is narrower: the physical descriptor, target-construction protocol, target-measurement channel, channel-calibration assumptions, bridge class, and uncertainty model must each be declared rather than hidden inside one score.

Research program

One chain of inference, organized by scientific function

The site separates physical assumptions, target provenance, target measurement, measurement-channel calibration, mathematical consequences, empirical interfaces, and open bridge questions so no stage silently inherits a stronger claim than the previous one established.

Current theorem frontier

P71-P73 strengthen the target side of the bridge test

P71 asks whether the target is non-circular. P72 asks whether noisy observation preserves a target distinction. P73 asks when the binary channel stability required by P72 can be identified from repeated views instead of simply assumed.

P71

Target-provenance non-circularity

If a target is constructed as a function or descriptor-only channel of the tested physical descriptor, factorization or screening-off holds by construction.

P72

Target-measurement robustness

Under a nondifferential target channel, \(I(Y;\Omega\mid T)\le I(E^\star;\Omega\mid T)\). Measurement can attenuate or erase a real witness under the stated model.

P73

Three-view channel-stability identifiability

Two heterogeneous binary views identify only one reliability product. Three nonzero conditionally independent views identify all three stability magnitudes, while retaining one global latent-label orientation ambiguity.

Falsification and evidence

The framework is designed to fail informatively

A scientific bridge proposal should expose conditions under which its descriptor, target, measurement model, channel calibration, or bridge class is shown inadequate.

Target circularity

Reject evidential use when the target construction already forces factorization through the tested descriptor.

Measurement contamination

Reject P72 transfer if the observed target depends on the underlying state beyond the declared latent target and descriptor.

Repeated-view model failure

Do not treat P73 agreement as reliability when shared bias, conditional dependence, asymmetry, or drift invalidates the declared model.

Descriptor collision

Find same-descriptor cases whose independently justified target distributions remain distinguishable.

Finite-data failure

Do not promote an empirical gap when its confidence lower bound remains zero.
