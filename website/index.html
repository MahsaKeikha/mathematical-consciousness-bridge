Open research in mathematical physics and scientific inference

When is a physical description enough to support a claim about experience?

This project builds ways to test that question without assuming the answer. It asks what must be described, measured, challenged, and verified before a proposed connection between physics and experience deserves scientific confidence.

The project in one minute

Four questions organize the research

You do not need a background in physics, mathematics, neuroscience, or philosophy to follow the basic logic.

1

What exactly are we describing?

Before making a claim, we need to know which physical information is included and which information may have been left out.

2

What exactly are we trying to explain?

The target should be defined independently enough that we do not quietly build the desired answer into the evidence.

3

Can the proposed model be wrong?

A scientific model becomes meaningful when observations can challenge it, not only when parameters can be fitted to data.

4

Does the conclusion survive uncertainty?

Finite data, noisy measurements, and numerical approximations should not be mistaken for stronger evidence than they provide.

Why this is interesting

Correlation is not yet explanation

Science can measure enormous detail about a physical system. But a rich physical description does not automatically tell us whether it contains every distinction needed for an experience related claim.

This project turns that broad problem into smaller questions that can be stated clearly, tested separately, and audited by other researchers.

The aim is not to hide uncertainty behind sophisticated mathematics. The aim is to make every assumption and every possible failure easier to see.

A simple way to picture the problem

Think of a physical description as a map.

A map can be excellent for one purpose and still leave out information needed for another. A subway map can guide you across a city while telling you almost nothing about the color of the buildings above it.

The research asks when a proposed physical map contains enough information for the particular question being asked.

Scientific boundary

The final bridge remains open

This repository does not claim that an equation, latent variable, neural signature, quantum effect, or information measure has been identified as consciousness.

A model can fail without telling us which alternative is correct. A theorem can be valid under assumptions that still require empirical justification. The purpose of the project is to make those distinctions explicit rather than blur them.

For readers who want the complete record

Every deeper result remains auditable

The public site is intentionally easy to read. The GitHub repository keeps the full theorem record, equation provenance, implementations, tests, figures, and reproducibility instructions for technical review.
