# Proposition 71: target-provenance non-circularity and descriptor-derived target vacuity

**Status:** proved mathematical non-circularity theorem for a declared target-construction protocol.

## 1. Purpose

Proposition 19 makes the physical-to-experiential bridge question mathematically precise. Given a physical descriptor

\[
T:\Omega\to\mathcal T
\]

and a target

\[
E:\Omega\to\mathcal E,
\]

P19 asks whether

\[
E=B\circ T
\]

or, in the stochastic setting, whether

\[
I(E;\Omega\mid T)=0.
\]

P19 explicitly requires the target to be independently specified. P71 explains why that requirement is not optional.

If the target is itself constructed from the physical descriptor, then the bridge test can be satisfied by definition. In that case a successful factorization does not show that the physical descriptor explains an independently specified target. The target has already been forced to live on the descriptor fibers.

P71 proves this deterministic and stochastic vacuity result, extends it to learned target rules, and proves a provenance non-identifiability result: an observed zero P19 residual cannot by itself reveal whether the target was genuinely specified independently or generated through a descriptor-only channel.

The theorem therefore separates two questions that must not be conflated:

\[
\boxed{
\text{Does }E\text{ factor through }T?
}
\]

and

\[
\boxed{
\text{Was }E\text{ specified independently enough for that factorization to be evidentially meaningful?}
}
\]

The first is a property of values or probability laws. The second is a property of scientific provenance and experimental design.

---

## 2. Deterministic setup

Let \(\Omega\) be a set of admissible states or histories and let

\[
T:\Omega\to\mathcal T
\]

be the declared physical descriptor.

Suppose a target is constructed by choosing a map

\[
h:\mathcal T\to\mathcal E
\]

and defining

\[
\boxed{
E_h(\omega)=h(T(\omega)).
}
\]

Such a target will be called **descriptor-derived** relative to \(T\).

This definition is about provenance. It does not say that \(E_h\) is a bad measurement in every scientific context. It says that \(E_h\) cannot independently test whether \(T\) is sufficient for \(E_h\), because sufficiency has already been inserted into the target definition.

---

## 3. P71A: deterministic target-vacuity theorem

### Proposition

If

\[
E_h=h\circ T,
\]

then all of the following hold identically:

1. the P19 exact bridge exists, with \(B=h\) on \(\operatorname{Im}(T)\);
2. \(E_h\) is constant on every fiber of \(T\);
3. the P19 collision set is empty;
4. if \((\Omega,T,E_h)\) is assigned any finite probability law consistent with the deterministic construction, then

\[
H(E_h\mid T)=0
\]

and

\[
\boxed{
I(E_h;\Omega\mid T)=0.
}
\]

### Proof

The first statement follows directly from the construction:

\[
E_h(\omega)=h(T(\omega))=(h\circ T)(\omega).
\]

Now suppose

\[
T(\omega_1)=T(\omega_2).
\]

Then

\[
E_h(\omega_1)
=h(T(\omega_1))
=h(T(\omega_2))
=E_h(\omega_2).
\]

Therefore no pair with equal \(T\) can have unequal \(E_h\), so the P19 exact collision test cannot reject this target construction.

In the finite probabilistic case, \(E_h\) is a deterministic function of \(T\), so

\[
H(E_h\mid T)=0.
\]

Because \(E_h\) is also a deterministic function of \(\Omega\) through \(T\), the P19 deterministic-target identity gives

\[
I(E_h;\Omega\mid T)=H(E_h\mid T)=0.
\]

Thus both the exact and stochastic sufficiency tests are satisfied by construction. \(\square\)

---

## 4. Scientific consequence of P71A

The conclusion is not

> descriptor-derived targets are always scientifically useless.

The conclusion is narrower:

> a descriptor-derived target cannot serve as independent evidence that the same descriptor is sufficient for that target.

For example, if a scalar neural score is computed from \(T\) and then called the target, demonstrating that the score can be reconstructed from \(T\) is mathematically guaranteed. The result may validate software or reproducibility, but it does not test a physical-to-experiential bridge.

This distinction is especially important when a candidate consciousness label, state score, or classifier output is built from the same neural, causal, or quantum representation that is later claimed to explain it.

## 5. P71B: stochastic descriptor-channel vacuity

The same problem persists when the target is stochastic rather than deterministic.

Let \(P_{\Omega,T}\) be any finite joint law consistent with the declared descriptor. Let

\[
K(e\mid t)
\]

be any stochastic target channel depending only on \(T\). Construct

\[
\boxed{
P(\omega,t,e)
=P(\omega,t)K(e\mid t).
}
\]

### Proposition

Every target generated by this descriptor-only channel satisfies

\[
\boxed{
E\perp\!\!\!\perp\Omega\mid T
}
\]

and therefore

\[
\boxed{
I(E;\Omega\mid T)=0.
}
\]

### Proof

For every \((\omega,t)\) with positive mass,

\[
P(E=e\mid\Omega=\omega,T=t)
=K(e\mid t).
\]

But

\[
P(E=e\mid T=t)=K(e\mid t)
\]

as well, because summing over \(\omega\) leaves the same normalized target channel. Hence

\[
P(E\mid\Omega,T)=P(E\mid T),
\]

which is the conditional-independence criterion from P19. For finite alphabets this is equivalent to zero conditional mutual information. \(\square\)

The stochastic P19 residual therefore cannot distinguish a genuinely explanatory screening-off relation from a target channel that was deliberately generated to screen off through \(T\).

## 6. P71C: learned-target corollary

A common response to circularity is to train a target predictor on one dataset and evaluate it on held-out data. This can be necessary for statistical generalization, but it does not automatically create independent target provenance.

Let \(D\) denote a training artifact, training dataset, fitted parameter set, or frozen model. For each realized \(D=d\), let

\[
h_d:\mathcal T\to\mathcal E
\]

be the learned rule and define the test-time target

\[
\boxed{
\widehat E=h_D(T).
}
\]

### Proposition

Conditional on the learned artifact \(D\),

\[
\boxed{
I(\widehat E;\Omega\mid T,D)=0.
}
\]

If in addition

\[
D\perp\!\!\!\perp\Omega\mid T,
\]

then

\[
\boxed{
I(\widehat E;\Omega\mid T)=0.
}
\]

### Proof

Conditional on \(D=d\), the target is the deterministic function

\[
\widehat E=h_d(T).
\]

P71A therefore gives

\[
I(\widehat E;\Omega\mid T,D=d)=0
\]

for every positive-probability \(d\), and averaging over \(D\) gives the first result.

For the second result, conditional on \(T=t\), the assumption

\[
D\perp\!\!\!\perp\Omega\mid T
\]

means that the distribution of \(D\) does not change with \(\Omega\). Since \(\widehat E\) is a function only of \((T,D)\), summing over \(D\) yields

\[
P(\widehat E\mid\Omega,T)=P(\widehat E\mid T).
\]

P19 then gives zero conditional mutual information. \(\square\)

### Interpretation

Train/test separation can prevent one form of statistical double use. It does not change the mathematical fact that a target computed only from \(T\) is a function or channel of \(T\). If the scientific question is whether \(T\) explains an independently specified experiential target, the target must have provenance outside the tested descriptor construction.

This point is related to the broader warning against circular analysis in systems neuroscience. Kriegeskorte, Simmons, Bellgowan, and Baker showed why selection and analysis based on non-independent data can invalidate inference. P71 addresses a different but related structural issue: even perfect statistical separation does not make a descriptor-derived target independent in the sense required by the bridge problem.

Reference: N. Kriegeskorte, W. K. Simmons, P. S. F. Bellgowan, and C. I. Baker, "Circular analysis in systems neuroscience: the dangers of double dipping," *Nature Neuroscience* 12 (2009), 535-540. DOI: 10.1038/nn.2303.

## 7. P71D: target-provenance non-identifiability theorem

A deeper limitation follows from the stochastic factorization itself.

Suppose an observed finite joint law satisfies

\[
\boxed{
I(E;\Omega\mid T)=0.
}
\]

Then P19 gives

\[
P(E\mid\Omega,T)=P(E\mid T).
\]

Define the descriptor-only channel

\[
\boxed{
K(e\mid t):=P(E=e\mid T=t).
}
\]

### Proposition

The complete observed joint law can be reproduced exactly as

\[
\boxed{
P(\omega,t,e)
=P(\omega,t)K(e\mid t).
}
\]

Therefore an observed zero P19 residual is observationally compatible with a descriptor-derived target-generation mechanism.

### Proof

Conditional independence gives

\[
P(\omega,t,e)
=P(\omega,t)P(e\mid\omega,t)
=P(\omega,t)P(e\mid t).
\]

Substituting the declared channel \(K(e\mid t)=P(e\mid t)\) proves the result. \(\square\)

### Consequence

No statistic computed only from the same observed joint law \(P_{\Omega,T,E}\) can prove that the target was conceptually or procedurally specified independently of \(T\). The values alone do not carry their scientific provenance.

This is why P71 treats target independence as a **protocol requirement**, not as a request to make \(E\) statistically independent of \(T\). A real bridge may produce very strong dependence between \(T\) and \(E\). What must be independent is the construction and evidential provenance of the target, not necessarily its observed value.

## 8. P71E: non-vacuity requirement for a bridge test

P71 motivates the following necessary design rule.

A P19 bridge test has non-vacuous evidential content only if the target-construction protocol does not force

\[
E=h(T)
\]

or, in the stochastic case,

\[
\Omega\to T\to E
\]

by design.

This condition is necessary, not sufficient. Passing it does not prove that the target is a valid measure of experience.

For a serious physical-to-experiential experiment, the target provenance should declare at least:

1. the raw target-side observations or reports;
2. the rule used to convert those observations into the target variable;
3. whether the physical descriptor \(T\), or any deterministic transform of it, enters that rule;
4. whether model fitting, feature selection, or threshold selection used the bridge-evaluation data;
5. which parts of the target protocol were frozen before testing the physical bridge;
6. which assumptions connect the target-side observations to experiential distinctions;
7. which falsification would count against the target model itself.

The target may still be imperfect, noisy, theory-laden, or behaviorally mediated. P71 does not solve the measurement problem of consciousness. It makes one minimum requirement explicit: the target cannot be manufactured from the tested physical descriptor and then used as independent evidence for that descriptor.

## 9. Synthetic finite example

Let

\[
\Omega\in\{0,1,2,3\}
\]

be uniformly distributed and define the physical descriptor

\[
\boxed{
T(\Omega)=\Omega\bmod 2.
}
\]

### 9.1 Descriptor-derived target

Define

\[
E_{\rm circ}=T.
\]

Then

\[
E_{\rm circ}=\operatorname{id}\circ T,
\]

there are no P19 fiber collisions, and

\[
\boxed{
I(E_{\rm circ};\Omega\mid T)=0.
}
\]

The zero residual is guaranteed by construction.

### 9.2 Separately declared synthetic target

Now define a target without using \(T\):

\[
\boxed{
E_{\rm ext}(\Omega)=\mathbf 1\{\Omega\ge2\}.
}
\]

The physical pairs \((0,2)\) and \((1,3)\) have the same \(T\) value but different target values. Hence the P19 collision test rejects exact factorization.

Because \(E_{\rm ext}\) is deterministic from \(\Omega\),

\[
I(E_{\rm ext};\Omega\mid T)
=H(E_{\rm ext}\mid T).
\]

Within each parity class the target is equiprobable, so

\[
\boxed{
I(E_{\rm ext};\Omega\mid T)=\log 2\approx0.6931\text{ nats}.
}
\]

This example is deliberately synthetic. \(E_{\rm ext}\) is not asserted to represent experience. Its role is to show the difference between a target whose sufficiency is guaranteed by its construction and a separately declared target that can actually challenge the descriptor.

## 10. What P71 does and does not establish

P71 establishes:

- exact factorization is automatic for deterministic descriptor-derived targets;
- stochastic screening-off is automatic for descriptor-only target channels;
- a fixed learned rule remains descriptor-derived even when evaluated on held-out data;
- zero P19 residual cannot, from observed values alone, establish independent target provenance;
- target provenance must therefore be declared as part of the bridge-test protocol.

P71 does **not** establish:

- a correct mathematical space of conscious experience;
- that subjective report is sufficient or necessary for consciousness;
- that no-report measures are automatically independent targets;
- that statistical dependence between \(T\) and \(E\) is circular;
- that a positive residual proves nonphysical consciousness;
- that a zero residual proves physicalism;
- that quantum or classical physics is complete or incomplete.

---

## 11. Relation to consciousness measurement

Consciousness experiments face a genuine target problem. Overt report can introduce post-perceptual processes, while no-report paradigms replace report with indirect physiological or behavioral readouts that require their own validation. The literature therefore distinguishes neural signals of interest from report, task, attention, memory, and other possible confounds.

P71 does not select one measurement philosophy. It supplies a more basic mathematical requirement that applies to all of them: whatever target is used, its construction must not already encode the factorization being tested.

This is compatible with the broader consciousness literature emphasizing the need to separate neural correlates of experience from prerequisites and consequences. See, for example, Koch, Massimini, Boly, and Tononi, *Nature Reviews Neuroscience* 17 (2016), 307-321, DOI 10.1038/nrn.2016.22.

## 14. Scientific boundary

P71 is a theorem about the logic of target construction in a bridge test.

It does not solve the physical-to-experiential bridge. Instead, it removes a class of false solutions that would satisfy the mathematics only because the target had been defined from the physical descriptor in advance.

The scientific contribution is therefore a non-circularity guard:

\[
\boxed{
\text{bridge evidence requires a target whose provenance does not already impose the bridge.}
}
\]

That guard is necessary before a future theorem can make a scientifically meaningful claim that a physical descriptor is sufficient, insufficient, or incomplete relative to experiential structure.
