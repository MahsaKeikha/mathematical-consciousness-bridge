## The current frontier in one paragraph

P75 begins by separating **parameter identifiability** from **model adequacy**. P76 moves adequacy checks into finite data. P77 asks whether the full empirical confidence region is separated from the full declared model set. P78-P82 make continuous-family separation increasingly certifiable through exact-rational global bounds, sampling-radius certification, normalization, projected events, and nested contrasts. P83-P87 add dependency-aware parity and multi-event functionals, culminating in 39,600 exact bounded primitive P87 functionals. P88 then asks whether one discovery-selected box/functional pair survives **independent validation**.

For the question-by-question artifact trail, use the [Research Traceability Index](research_traceability_index.md#target-side-research-frontier-p71-p88).

## How a mature result is audited

Where the artifacts exist, the public record follows this chain:

**scientific question → assumptions → theorem → proof → provenance → implementation → tests → figure → reproduction → interpretation boundary**

This ordering is deliberate. A reader can stop after the result summary, while a reviewer can continue all the way to exact source and regression checks.

---

## Scientific boundary

This repository distinguishes mathematical correctness from scientific interpretation. Rejection of a declared model does not prove consciousness is nonphysical. A latent variable is not automatically consciousness. Non-rejection is not model validation. The physical-to-experiential bridge remains open.
