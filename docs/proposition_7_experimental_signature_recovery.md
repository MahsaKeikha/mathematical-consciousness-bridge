# Proposition 7: experimental recoverability of a complete bridge signature

## Physical question

Proposition 6 defines the mathematical target for a complete physical consciousness signature:

\[
F_*(p)=F_*(p')
\iff
\bar B(p)=\bar B(p').
\]

But a physical signature is scientifically useful only if measurements and interventions contain enough information to recover it.

Proposition 7 gives the exact condition under which a declared experiment class can determine a bridge-complete physical signature.

---

# 1. Setup

Let

\[
F_*:\mathcal Q_P\to\mathcal Z_*
\]

be bridge-complete for

\[
\bar B:\mathcal Q_P\to\mathcal Q_E.
\]

Thus

\[
\boxed{
F_*(p)=F_*(p')
\iff
\bar B(p)=\bar B(p').
}
\]

Let \(\Pi\) be an admissible experiment class.

For each physical class \(p\in\mathcal Q_P\) and protocol \(\pi\in\Pi\), let

\[
P^{\pi,p}
\]

be the observable probability law generated by the declared physical and measurement model.

Define the complete experimental fingerprint

\[
\boxed{
\Psi_{\Pi}(p)
=
\big(P^{\pi,p}\big)_{\pi\in\Pi}.
}
\]

Its image is

\[
\mathcal O_{\Pi}
=
\operatorname{Im}(\Psi_{\Pi}).
\]

---

# 2. Definition: experimental recoverability

The physical feature \(F_*\) is **recoverable from \(\Pi\)** when there exists a decoder

\[
D_F:\mathcal O_{\Pi}\to\operatorname{Im}(F_*)
\]

such that

\[
\boxed{
F_*=D_F\circ\Psi_{\Pi}.
}
\]

This definition allows the observable fingerprint to contain additional physical information unrelated to the bridge. The experiment need not be constant on feature fibers; it only has to retain enough information to determine the feature.

---

# 3. Proposition

## Proposition 7

The following are equivalent.

### A. Decoder existence

There exists a unique map

\[
D_F:\mathcal O_{\Pi}\to\operatorname{Im}(F_*)
\]

such that

\[
\boxed{
F_*=D_F\circ\Psi_{\Pi}.
}
\]

### B. Observational fibers refine signature fibers

For every \(p,p'\in\mathcal Q_P\),

\[
\boxed{
\Psi_{\Pi}(p)=\Psi_{\Pi}(p')
\Longrightarrow
F_*(p)=F_*(p').
}
\]

### C. No signature-different observational collision

There does not exist a pair \(p,p'\) satisfying

\[
\boxed{
\Psi_{\Pi}(p)=\Psi_{\Pi}(p')
\quad\text{and}\quad
F_*(p)\ne F_*(p').
}
\]

When these conditions hold and \(F_*\) is bridge-complete, there also exists a bridge decoder

\[
D_B:\mathcal O_{\Pi}\to\operatorname{Im}(\bar B)
\]

such that

\[
\boxed{
\bar B
=
\iota\circ D_B\circ\Psi_{\Pi},
}
\]

where \(\iota\) includes the realized bridge image into \(\mathcal Q_E\).

Thus experimental recoverability of a complete signature implies recoverability of the bridge output on the declared physical domain.

---

# 4. Proof

## 4.1 A implies B

Assume

\[
F_*=D_F\circ\Psi_{\Pi}.
\]

If

\[
\Psi_{\Pi}(p)=\Psi_{\Pi}(p'),
\]

then

\[
F_*(p)
=
D_F(\Psi_{\Pi}(p))
=
D_F(\Psi_{\Pi}(p'))
=
F_*(p').
\]

Therefore B holds.

## 4.2 B implies A

Assume

\[
\Psi_{\Pi}(p)=\Psi_{\Pi}(p')
\Longrightarrow
F_*(p)=F_*(p').
\]

For any observable fingerprint

\[
o\in\mathcal O_{\Pi},
\]

choose \(p\) with

\[
\Psi_{\Pi}(p)=o
\]

and define

\[
\boxed{
D_F(o)=F_*(p).
}
\]

If \(p'\) is another physical class with the same fingerprint, the assumption gives

\[
F_*(p')=F_*(p),
\]

so \(D_F\) is well defined.

For every \(p\),

\[
D_F(\Psi_{\Pi}(p))=F_*(p),
\]

hence

\[
F_*=D_F\circ\Psi_{\Pi}.
\]

Uniqueness follows because every element of \(\mathcal O_{\Pi}\) is realized by some \(p\).

## 4.3 B if and only if C

Condition C is exactly the negation of a counterexample to condition B.

## 4.4 Bridge recovery

Because \(F_*\) is bridge-complete, Proposition 5 gives a unique map

\[
g_*:\operatorname{Im}(F_*)\to\operatorname{Im}(\bar B)
\]

with

\[
\bar B=g_*\circ F_*.
\]

Using

\[
F_*=D_F\circ\Psi_{\Pi},
\]

we obtain

\[
\bar B
=
g_*\circ D_F\circ\Psi_{\Pi}.
\]

Define

\[
D_B=g_*\circ D_F.
\]

Then

\[
\bar B
=
\iota\circ D_B\circ\Psi_{\Pi}.
\]

\[
\boxed{\text{QED}}
\]

---

# 5. Experimental no-go corollary

Suppose a proposed complete signature distinguishes two physical systems:

\[
F_*(p)\ne F_*(p').
\]

If every admissible protocol produces the same observable law,

\[
\boxed{
P^{\pi,p}=P^{\pi,p'}
\quad
\text{for all }\pi\in\Pi,
}
\]

then

\[
\Psi_{\Pi}(p)=\Psi_{\Pi}(p')
\]

and no decoder based on that experiment class can recover \(F_*\).

If \(F_*\) is bridge-complete, the same pair also has different bridge outputs, so the experiment class cannot recover the bridge distinction.

This provides an exact no-go condition for an empirically inadequate experiment family.

---

# 6. Why this is stronger than ordinary correlation

A correlation between a measured quantity and a consciousness label does not establish recoverability of a complete signature.

Proposition 7 requires the full implication

\[
\Psi_{\Pi}(p)=\Psi_{\Pi}(p')
\Longrightarrow
F_*(p)=F_*(p').
\]

The experiment fingerprint must not collapse two physically realized states that the complete signature says belong to different experiential classes.

This is a structural identifiability requirement, not merely a predictive-accuracy requirement on one dataset.

---

# 7. Relation to Proposition 4 experiment design

Proposition 4 asks which protocols separate competing theory predictions most efficiently.

Proposition 7 asks a complementary question: does the selected protocol family preserve enough information to decode the target complete physical signature?

For a finite physical domain, one can search for a protocol family \(S\subseteq\Pi\) such that

\[
\boxed{
F_*(p)\ne F_*(p')
\Longrightarrow
\exists\pi\in S:
P^{\pi,p}\ne P^{\pi,p'}.
}
\]

This is again a pair-cover problem, now over **signature-different physical pairs** rather than theory pairs.

Thus the same experiment-design machinery can be used at two levels:

1. discriminate competing theories;
2. recover a proposed complete signature within a theory.
