# Proposition 79: Joint Statistical-Computational Power for Full-Law Rejection

## Status

**Proved sufficient finite-sample power theorem with an executable exact-margin interface and numerical planning helper.**

P79 continues the [P77 full-law model-set separation theorem](proposition_77_full_law_model_set_separation.md) and the [P78 certified continuous model-separation theorem](proposition_78_certified_continuous_model_separation.md).

P77 states when a finite-sample confidence region is separated from a declared observed-law model set. P78 supplies a certified lower bound on empirical distance to the continuous P75 four-view latent family and an explicit deterministic optimization-gap bound. P79 asks the next prospective question:

> **How much true model separation, sample size, and certified optimization accuracy are jointly sufficient to guarantee a declared rejection level and a declared power level?**

The answer is a sufficient margin condition. It is not an exact power function and it is not a model-acceptance procedure.

---

## 1. Setup

Let \(\mathcal X\) be a finite observable alphabet with

\[
|\mathcal X|=K.
\]

Let \(P\) be the true population law, \(\widehat P_n\) the empirical law from \(n\) IID observations, and \(\mathcal M\subseteq\Delta_{K-1}\) a declared nonempty observed-law model set.

Use the \(L^\infty\) model-set distance

\[
d_\infty(R,\mathcal M)
=
\inf_{Q\in\mathcal M}\|R-Q\|_\infty.
\]

P77 uses the simultaneous empirical-law radius

\[
\boxed{
\varepsilon_{n,K}(q)
=
\sqrt{\frac{\log(2K/q)}{2n}}
}
\]

for any \(q\in(0,1)\). Hoeffding's inequality plus a union bound gives

\[
\Pr_P\left(
\|\widehat P_n-P\|_\infty
\le
\varepsilon_{n,K}(q)
\right)
\ge1-q.
\]

The map \(R\mapsto d_\infty(R,\mathcal M)\) is 1-Lipschitz under \(L^\infty\):

\[
\boxed{
\left|
d_\infty(R,\mathcal M)
-
d_\infty(S,\mathcal M)
\right|
\le
\|R-S\|_\infty.
}
\]

For the P75 four-binary-view application, \(K=16\) and \(\mathcal M=\mathcal M_{4,2}\).

## 2. P79A: certified three-way empirical decision

Suppose a certified computation returns

\[
L_n
\le
d_\infty(\widehat P_n,\mathcal M)
\le U_n,
\]

where:

- \(L_n\) is a mathematically valid lower bound;
- \(U_n\) is generated by an explicit admissible model candidate and is therefore an upper bound;
- \(r_n\) is a mathematically valid upper bound on the P77 rejection radius.

Then exactly three computational conclusions are available from these certified quantities.

### Case 1: rejection certificate

If

\[
\boxed{L_n>r_n,}
\]

then

\[
d_\infty(\widehat P_n,\mathcal M)>r_n,
\]

so the P77 confidence region is disjoint from \(\mathcal M\).

### Case 2: explicit overlap witness

If

\[
\boxed{U_n\le r_n,}
\]

then the explicit admissible model candidate used to construct \(U_n\) lies inside the closed P77 confidence ball. Hence the confidence ball and model set have nonempty intersection.

This is an overlap witness. It is **not** evidence that the model is true.

### Case 3: unresolved bracket

If

\[
\boxed{L_n\le r_n<U_n,}
\]

then the current certified optimization bracket does not decide whether the confidence ball intersects the model set. More optimization, more data, or both may be required.

This third state is scientifically important. An unresolved numerical bracket must not be silently converted into either rejection or model acceptance.

---

## 3. P79B: P77 Type I control is unchanged

Fix a rejection level \(\alpha\in(0,1)\), and let

\[
r_{\alpha,n}
=
\varepsilon_{n,K}(\alpha).
\]

Suppose the decision rule rejects only when a certified empirical lower bound satisfies

\[
L_n>r_{\alpha,n}.
\]

Under the null hypothesis

\[
P\in\mathcal M,
\]

on the P77 confidence event

\[
\|\widehat P_n-P\|_\infty
\le r_{\alpha,n},
\]

we have

\[
d_\infty(\widehat P_n,\mathcal M)
\le
\|\widehat P_n-P\|_\infty
\le r_{\alpha,n}.
\]

Because \(L_n\le d_\infty(\widehat P_n,\mathcal M)\), rejection is impossible on that event. Therefore

\[
\boxed{
\sup_{P\in\mathcal M}
\Pr_P(\text{reject})
\le\alpha.
}
\]

P79 does not spend any additional Type I error merely because the model-set distance is computed approximately, provided the computation supplies a valid lower bound.

---

## 4. P79C: joint statistical-computational power theorem

Now fix a desired Type II error level \(\beta\in(0,1)\).

Assume the true population law satisfies a declared separation condition

\[
\boxed{
d_\infty(P,\mathcal M)\ge\Delta_0,}
\]

for some \(\Delta_0>0\).

Also assume the certified optimizer satisfies the deterministic gap guarantee

\[
\boxed{
0
\le
d_\infty(\widehat P_n,\mathcal M)-L_n
\le\eta,
}
\]

for some declared \(\eta\ge0\).

For P78, \(\eta\) can be supplied by its certified parameter-partition mesh bound.

Consider the event

\[
\mathcal E_\beta
=
\left\{
\|\widehat P_n-P\|_\infty
\le
\varepsilon_{n,K}(\beta)
\right\}.
\]

By the same finite-alphabet concentration inequality,

\[
\Pr_P(\mathcal E_\beta)\ge1-\beta.
\]

On \(\mathcal E_\beta\), the 1-Lipschitz property of distance to a set gives

\[
d_\infty(\widehat P_n,\mathcal M)
\ge
d_\infty(P,\mathcal M)
-
\varepsilon_{n,K}(\beta)
\ge
\Delta_0-arepsilon_{n,K}(\beta).
\]

The certified optimization-gap inequality then yields

\[
L_n
\ge
d_\infty(\widehat P_n,\mathcal M)-\eta
\ge
\Delta_0-arepsilon_{n,K}(\beta)-\eta.
\]

Therefore, if

\[
\boxed{
\Delta_0
>
\varepsilon_{n,K}(\alpha)
+
\varepsilon_{n,K}(\beta)
+
\eta,
}
\]

then on \(\mathcal E_\beta\),

\[
L_n>\varepsilon_{n,K}(\alpha),
\]

and the P77 rule rejects.

Hence:

\[
\boxed{
\Pr_P(\text{reject})
\ge1-\beta
\quad
\text{for every }P\text{ satisfying }
d_\infty(P,\mathcal M)\ge\Delta_0,
}
\]

whenever the displayed sufficient margin condition holds.

Together with P79B, the rule has Type I error at most \(\alpha\) and power at least \(1-\beta\) over the declared separated alternative class.

### Interpretation

The population separation budget is consumed by three distinct quantities:

1. the P77 rejection radius at level \(\alpha\);
2. the alternative-side concentration radius at level \(\beta\);
3. the certified deterministic optimization error \(\eta\).

This decomposition is the central P79 handoff between statistics and certified computation.

## 5. P79D: sufficient sample-size formula

For the Hoeffding specialization,

\[
\varepsilon_{n,K}(\alpha)
+
\varepsilon_{n,K}(\beta)
=
\frac{
\sqrt{\log(2K/\alpha)}
+
\sqrt{\log(2K/\beta)}
}{\sqrt{2n}}.
\]

If

\[
0\le\eta<\Delta_0,
\]

then the strict sufficient condition

\[
\varepsilon_{n,K}(\alpha)
+
\varepsilon_{n,K}(\beta)
<
\Delta_0-\eta
\]

is equivalent to

\[
\boxed{
n
>
\frac{
\left(
\sqrt{\log(2K/\alpha)}
+
\sqrt{\log(2K/\beta)}
\right)^2
}{
2(\Delta_0-\eta)^2
}.
}
\]

This is a **sufficient prospective planning rule**. It is conservative because it inherits the cellwise Hoeffding plus union-bound construction. It is not claimed to be minimax optimal and it is not an exact power calculation.

---

## 6. P79E: computational tolerance budget

For fixed \(n,K,\alpha,\beta\), define

\[
\boxed{
\eta_{\max}
=
\Delta_0
-
\varepsilon_{n,K}(\alpha)
-
\varepsilon_{n,K}(\beta).
}
\]

Any certified optimization error satisfying

\[
0\le\eta<\eta_{\max}
\]

is sufficient for the P79C power guarantee.

If

\[
\eta_{\max}\le0,
\]

then no nonnegative optimization tolerance can satisfy this **particular sufficient theorem** at the current sample size and declared separation margin. That does **not** imply that the actual test has zero power. It says only that this conservative guarantee cannot certify the requested power at that design point.

This distinction prevents a failed sufficient certificate from being misinterpreted as an impossibility theorem.

---

## 7. P79F: prospective margin provenance

The quantity \(\Delta_0\) is an alternative-class design parameter, not a statistic automatically learned from the same test sample.

For a prospective power guarantee, \(\Delta_0\) must be:

- prespecified as the smallest scientifically relevant model-set separation;
- justified from independent pilot information or external constraints;
- or explicitly treated as a sensitivity parameter across a range of values.

If the same data are used after the fact to choose a favorable \(\Delta_0\), the displayed prospective power guarantee no longer has the interpretation stated above without an additional selection analysis.

P79 therefore keeps **planning-margin provenance** separate from the observed rejection calculation.

## 8. Synthetic numerical planning example

Take the P75 four-view alphabet size

\[
K=16,
\]

and choose

\[
\alpha=0.05,
\qquad
\beta=0.20,
\qquad
\Delta_0=0.20,
\qquad
\eta=0.02.
\]

The sufficient sample-size threshold is

\[
\frac{
\left(
\sqrt{\log(32/0.05)}
+
\sqrt{\log(32/0.20)}
\right)^2
}{2(0.20-0.02)^2}
\approx354.779.
\]

Because the theorem requires a strict inequality, the smallest integer sample size satisfying this numerical planning rule is

\[
\boxed{n=355.}
\]

At \(n=355\), the numerical sum

\[
\varepsilon_{355,16}(0.05)
+
\varepsilon_{355,16}(0.20)
+0.02
\]

is strictly below \(0.20\); at \(n=354\) it is not.

This example is synthetic and demonstrates the planning calculation only. It is not an empirical consciousness result and does not establish that \(\Delta_0=0.20\) is scientifically appropriate for any real target-measurement experiment.

## 9. Exact versus numerical certification

The implementation distinguishes two layers.

### Exact final comparison

The function `certified_joint_power_margin(...)` accepts `Fraction` inputs for:

- a certified lower bound on \(\Delta_0\);
- a certified upper bound on \(\varepsilon_{n,K}(\alpha)\);
- a certified upper bound on \(\varepsilon_{n,K}(\beta)\);
- a certified upper bound on \(\eta\).

It then performs the final strict inequality exactly in rational arithmetic.

### Numerical planning helper

The sample-size helper evaluates logarithms and square roots in ordinary floating-point arithmetic. It is useful for prospective planning and regression tests, but ordinary floating-point evaluation is not promoted to a formal interval certificate merely by being stored as a decimal or converted later to a rational number.

A formal claim should supply mathematically valid upper bounds in the directions required by the theorem.

## 10. Relation to standard statistics and optimization

The ingredients used by P79 are individually standard:

- Hoeffding concentration for bounded independent variables;
- a union bound across finite categorical cells;
- the 1-Lipschitz property of distance to a nonempty set under a norm;
- the distinction between Type I error and power;
- certified lower and upper bounds in global optimization.

P79 does **not** claim any of those general ingredients as new.

The repository-specific contribution is their explicit composition in the P77-P78 full-law testing architecture, producing:

1. a three-way certified computational decision;
2. a separate \(\alpha\)-level rejection radius and \(\beta\)-level alternative concentration radius;
3. an explicit deterministic optimization-error term \(\eta\);
4. a joint sufficient power inequality;
5. a sample-size/computation tradeoff and computational tolerance budget.
