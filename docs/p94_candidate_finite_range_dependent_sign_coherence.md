# P94 Candidate: Finite-Range Dependent Sign-Coherence Rejection

## Purpose

P93 converts the P92 nonlinear three-minor sign-coherence obstruction into a finite-sample rejection theorem under IID sampling. It uses only the seven observable cells entering the three P92 determinants.

P94 asks a narrower but important robustness question:

> Can the same rejection logic remain valid when nearby observations are temporally dependent?

Yes, under a declared finite-range dependence model and a common marginal four-view law.

P94 does **not** claim robustness to temporal drift. The common marginal law is essential because P92 constrains one population law. If the marginal distribution changes over time, the empirical average need not belong to the P75 family even when every time-specific law does.

---

## P94A. Sampling model

Let

\[
Z_1,\ldots,Z_n
\]

be observations taking values in the sixteen four-view cells.

Assume:

1. every \(Z_i\) has the same marginal law \(P\);
2. the sequence is \(m\)-dependent: sigma-fields generated by index sets separated by more than \(m\) time steps are independent.

Write

\[
q=m+1.
\]

For one selected observable cell \(x\), define

\[
X_i(x)=\mathbf 1\{Z_i=x\},
\qquad
p_x=P(x),
\qquad
Y_i(x)=X_i(x)-p_x.
\]

Then \(Y_i(x)\) has mean zero and lies in an interval of length one.

## P94B. Residue-class concentration

Partition the time indices by residue modulo \(q\):

\[
R_r=\{i: i\equiv r \pmod q\},
\qquad r=0,\ldots,q-1.
\]

Distinct indices in the same class differ by at least \(q=m+1\), so the random variables inside each fixed class are mutually independent.

Define

\[
S_r=\sum_{i\in R_r}Y_i(x),
\qquad
S=\sum_{r=0}^{q-1}S_r.
\]

The classes need not be independent of each other. For \(\lambda>0\), Holder's inequality with exponent \(q\) gives

\[
\begin{aligned}
\mathbb E e^{\lambda S}
&=\mathbb E\prod_{r=0}^{q-1}e^{\lambda S_r}\\
&\le
\prod_{r=0}^{q-1}
\left(\mathbb E e^{q\lambda S_r}\right)^{1/q}.
\end{aligned}
\]

Within each residue class, independence and Hoeffding's lemma give

\[
\mathbb E e^{q\lambda S_r}
\le
\exp\left(\frac{q^2\lambda^2 |R_r|}{8}\right).
\]

Therefore

\[
\boxed{
\mathbb E e^{\lambda S}
\le
\exp\left(\frac{q\lambda^2 n}{8}\right).
}
\]

Chernoff's method then yields

\[
\Pr(S\ge n\varepsilon)
\le
\exp\left(
-\lambda n\varepsilon+
\frac{q\lambda^2n}{8}
\right).
\]

Optimizing at

\[
\lambda=\frac{4\varepsilon}{q}
\]

gives

\[
\Pr(S\ge n\varepsilon)
\le
\exp\left(-\frac{2n\varepsilon^2}{q}\right).
\]

Applying the same argument to \(-S\) proves

\[
\boxed{
\Pr\left(
|\widehat P(x)-P(x)|>\varepsilon
\right)
\le
2\exp\left(-\frac{2n\varepsilon^2}{m+1}\right).
}
\]

For \(m=0\), this is exactly the IID Hoeffding bound used by P93.

## P94C. Seven-cell simultaneous radius

Let \(\mathcal J\) be the seven observable cells used by the three P92 determinants. A union bound gives

\[
\Pr\left(
\max_{x\in\mathcal J}
|\widehat P(x)-P(x)|
>\varepsilon
\right)
\le
14\exp\left(-\frac{2n\varepsilon^2}{m+1}\right).
\]

Thus

\[
\boxed{
\varepsilon^{(m)}_{n,7}(\alpha)
=
\sqrt{
\frac{(m+1)\log(14/\alpha)}{2n}
}
}
\]

satisfies

\[
\boxed{
\Pr\left(
\max_{x\in\mathcal J}
|\widehat P(x)-P(x)|
\le
\varepsilon^{(m)}_{n,7}(\alpha)
\right)
\ge1-\alpha.
}
\]

The dependence penalty is exactly the multiplicative factor \(m+1\) inside the squared radius.

## P94D. Sign-coherence rejection

P92 proves that every law in the complete mixed-prevalence P75 family satisfies

\[
D_1D_2D_3\ge0.
\]

P93 proves that if an empirical determinant \(\widehat D_i\) has sign-stability radius \(\widehat r_i\), then every nonnegative population matrix within entrywise distance strictly less than \(\widehat r_i\) preserves that determinant sign.

Therefore, under the P94 sampling assumptions, if

\[
\widehat D_1\widehat D_2\widehat D_3<0
\]

and

\[
\boxed{
\varepsilon^{(m)}_{n,7}(\alpha)
<
\min_i\widehat r_i,
}
\]

then on the simultaneous confidence event the population determinants have the same signs as their empirical counterparts. Hence

\[
D_1D_2D_3<0,
\]

which contradicts P92.

Thus

\[
\boxed{
\widehat D_1\widehat D_2\widehat D_3<0
\quad\text{and}\quad
\varepsilon^{(m)}_{n,7}(\alpha)<\min_i\widehat r_i
\Longrightarrow
P\notin\mathcal M_{75}
}
\]

with confidence at least \(1-\alpha\), conditional on the declared common-marginal \(m\)-dependence model.

## P94E. Exact-rational gate

The executable gate avoids an ordinary floating-point square root.

P79 gives a rational bracket

\[
\underline L
\le
\log(14/\alpha)
\le
\overline L.
\]

Therefore

\[
\frac{(m+1)\underline L}{2n}
\le
\left(\varepsilon^{(m)}_{n,7}(\alpha)\right)^2
\le
\frac{(m+1)\overline L}{2n}.
\]

P94 rejects only if the safe upper direction satisfies

\[
\boxed{
\frac{(m+1)\overline L}{2n}
<
\left(\min_i\widehat r_i\right)^2.
}
\]

Every quantity in this final executable comparison is rational.

## P94F. Established witness thresholds

For the established P92 witness,

\[
\min_i\widehat r_i=\frac1{24}.
\]

At \(\alpha=0.05\), the P94 condition becomes

\[
\sqrt{
\frac{(m+1)\log 280}{2n}
}
<\frac1{24},
\]

or equivalently

\[
\boxed{
n>288(m+1)\log 280.}
\]

P93 already certifies

\[
1622<288\log280<1623.
\]

P94 then uses exact P79 logarithm brackets to locate the integer crossing after multiplying by \(m+1\).

For \(m=1\), the first mathematical crossing is \(n=3246\), and the first exact denominator-24 witness replication is \(n=3264\).

For \(m=2\), the first mathematical crossing is \(n=4869\), and the first exact witness replication is \(n=4872\).

These are sufficient thresholds for this declared dependence model and this observed sign geometry. They are not minimax claims.

## Scientific boundary

P94 does not establish robustness to time-varying marginal laws, unknown or misspecified dependence range, long-range mixing, model acceptance under non-rejection, semantic validity of the latent state, nonphysicality of consciousness, or a completed physical-to-experiential bridge.

The next drift or mixing extension must control a separately stated population target rather than silently averaging incompatible time-specific laws.
