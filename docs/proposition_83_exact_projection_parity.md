# Proposition 83: Exact Projection-Parity Certificate for Continuous P75 Separation

## Status

**Proved conditional computational theorem.** P83 strengthens the P82 exact nested projection-contrast certificate for the same declared P75 four-view binary latent family and the same full-law $L_\infty$ distance.

P82 adds exact non-cylinder residual events of the form $A\setminus B$ for nested cylinders. P83 adds a different and complementary observable family: binary parity events on two, three, or four observed views. The parity probability has a closed product representation inside each P75 latent branch, which makes its complete parameter-box range exactly computable in rational arithmetic.

P83 is a model-distance certification result. It does not establish that the P75 latent state is consciousness, does not validate the P75 model when rejection fails, and does not close the physical-to-experiential bridge.

---

## 1. Why parity is a genuinely new test

The P75 model assumes that, conditional on the binary latent state, the four observed binary views are independent. P81 tests all 80 nonempty cylinder events. P82 additionally tests 256 residual events generated by nested cylinders. Both families can still miss dependence constraints that are naturally expressed by a signed or interaction-like observable rather than by one cylinder or one nested residual.

Parity provides the smallest exact example. For a selected set of observed views $J$ and a bit $b\in\{0,1\}$, define

\[
H(J,b)
=
\left\{
x\in\{0,1\}^4:
\bigoplus_{j\in J}x_j=b
\right\}.
\]

For $|J|\ge 2$, this is generally a union of several cylinders rather than a single P81 event or a single P82 nested residual.

The scientific role of P83 is narrow and explicit: it asks whether parity structure implied by the declared P75 conditional-independence model is compatible with the empirical sixteen-cell law on a parameter box.

## 2. Exact branchwise parity identity

Within latent branch $s\in\{-,+\}$, let

\[
X_j\sim\operatorname{Bernoulli}(q_{j,s})
\]

independently across the selected views. The standard Bernoulli parity identity gives

\[
\mathbb E_s\left[(-1)^{\sum_{j\in J}X_j}\right]
=
\prod_{j\in J}(1-2q_{j,s}).
\]

Therefore

\[
\boxed{
P_s\bigl(H(J,b)\bigr)
=
\frac{1+(-1)^b\prod_{j\in J}(1-2q_{j,s})}{2}.
}
\]

This identity is the key P83 reduction. It turns an observable dependence pattern into an exact product expression over the branch response parameters.

## 3. Exact parameter-box interval

Let a P78 axis-aligned parameter box be denoted by $B$. For branch $s$ and selected view $j$, suppose

\[
q_{j,s}\in[\ell_{j,s},u_{j,s}].
\]

Then

\[
1-2q_{j,s}
\in
[1-2u_{j,s},\,1-2\ell_{j,s}].
\]

Define

\[
Z_s(J)
=
\prod_{j\in J}(1-2q_{j,s}).
\]

The map $Z_s(J)$ is multi-affine in the response coordinates. On a rectangular box, every minimum and maximum of a multi-affine function is attained at a vertex. Hence

\[
\boxed{
Z_s(J)\in[z_s^L,z_s^U]
}
\]

exactly, where $z_s^L$ and $z_s^U$ are the minimum and maximum over the $2^{|J|}$ endpoint choices.

For even parity $b=0$,

\[
P_s(H(J,0))
\in
\left[
\frac{1+z_s^L}{2},
\frac{1+z_s^U}{2}
\right],
\]

and for odd parity $b=1$,

\[
P_s(H(J,1))
\in
\left[
\frac{1-z_s^U}{2},
\frac{1-z_s^L}{2}
\right].
\]

These branch intervals are exact.

## 4. Exact latent-mixture interval

Let prevalence satisfy

\[
\pi\in[\pi_L,\pi_U].
\]

Write the exact branch intervals as

\[
P_-(H)\in[h_-^L,h_-^U],
\qquad
P_+(H)\in[h_+^L,h_+^U].
\]

The minus-branch response parameters, plus-branch response parameters, and prevalence are disjoint coordinates of the P75 box. Their endpoint extrema are therefore jointly attainable. The mixture probability is

\[
q(H)
=(1-\pi)P_-(H)+\pi P_+(H).
\]

For the lower envelope, choose both branch lower endpoints; for the upper envelope, choose both branch upper endpoints. The remaining dependence on $\pi$ is affine, so only the two prevalence endpoints need to be checked:

\[
\boxed{
\ell_H(B)
=
\min_{\pi\in\{\pi_L,\pi_U\}}
\left[(1-\pi)h_-^L+\pi h_+^L\right],
}
\]

\[
\boxed{
u_H(B)
=
\max_{\pi\in\{\pi_L,\pi_U\}}
\left[(1-\pi)h_-^U+\pi h_+^U\right].
}
\]

Thus the P83 interval is the exact image interval of the parity event over the declared rational parameter box, not merely a conservative enclosure.

## 5. Transfer to full-law $L_\infty$ distance

For any event $S\subseteq\{0,1\}^4$, if

\[
\|\widehat p-q\|_\infty\le r,
\]

then

\[
|\widehat p(S)-q(S)|
\le
|S|r.
\]

Every parity event on a nonempty subset of binary views contains half of the full sixteen-cell outcome space. Therefore, for every P83 event,

\[
|H(J,b)|=8.
\]

It follows that

\[
\boxed{
\|\widehat p-q(\theta)\|_\infty
\ge
\frac{
d\!\left(
\widehat p(H(J,b)),
[\ell_H(B),u_H(B)]
\right)
}{8}.
}
\]

Define

\[
\boxed{
L_{\mathrm{par}}(B)
=
\max_{(J,b)\in\mathcal P}
\frac{
d\!\left(
\widehat p(H(J,b)),
[\ell_H(B),u_H(B)]
\right)
}{8}.
}
\]

## 6. The finite P83 family

One-view parity events are just ordinary binary cylinders and are already present in P81. P83 therefore begins at two selected views and includes both parity values for every two-, three-, and four-view subset.

The family size is

\[
\begin{aligned}
|\mathcal P|
&=2\left[{4\choose2}+{4\choose3}+{4\choose4}\right]\\
&=2(6+4+1)\\
&=\boxed{22}.
\end{aligned}
\]

This is deliberately small. The theorem does not require an exhaustive search over all $2^{16}$ subsets of the observed outcome space.

## 7. P83 theorem

For every admissible P78 parameter box $B$, define

\[
\boxed{
L_{83}(B)
=
\max\{L_{82}(B),L_{\mathrm{par}}(B)\}.
}
\]

Then:

1. $L_{83}(B)$ is a rigorous lower bound on the $L_\infty$ distance from $\widehat p$ to every P75 law generated inside $B$;
2. $L_{83}(B)\ge L_{82}(B)\ge L_{81}(B)\ge L_{80}(B)\ge L_{78}(B)$;
3. every P83 branchwise parity interval is exact over the declared response-coordinate box;
4. every P83 latent-mixture parity interval is exact over the full declared P75 box;
5. every interval endpoint and every P83 lower bound is exactly rational when the empirical law and box endpoints are rational;
6. for any finite partition $\mathcal B$ of the complete P75 parameter cube,

\[
\boxed{
L_{83}(\mathcal B)
:=
\min_{B\in\mathcal B}L_{83}(B)
\le
d_\infty(\widehat p,\mathcal M_{4,2});
}
\]

7. on the same partition,

\[
\boxed{
L_{83}(\mathcal B)\ge L_{82}(\mathcal B);
}
\]

8. explicit P75 parameter vectors remain valid global upper-bound witnesses;
9. the previously proved P78 mesh-width upper certificate remains valid and is retained unchanged. P83 does not assume a new convergence-rate theorem.

## 8. Proof

### 8.1 Exact branchwise interval

Conditional independence inside branch $s$ gives the parity identity

\[
P_s(H(J,b))
=
\frac{1+(-1)^b Z_s(J)}{2}.
\]

$Z_s(J)$ is multi-affine in the selected branch response coordinates. A multi-affine function on a rectangular box attains its extrema at vertices, so enumerating the $2^{|J|}$ endpoint combinations produces the exact product interval. The affine parity transform then gives the exact probability interval.

### 8.2 Exact mixture interval

The two latent branches use disjoint response coordinates, so their branch extrema can be attained simultaneously. Prevalence is a separate coordinate. For fixed branch endpoints the mixture is affine in prevalence, hence its extrema occur at $\pi_L$ or $\pi_U$. This proves the exact full-box interval.

### 8.3 Soundness of the lower bound

For $H=H(J,b)$,

\[
|\widehat p(H)-q(H)|
\le
8\|\widehat p-q\|_\infty.
\]

Every P75 law generated inside $B$ has $q(H)$ in the exact interval $[\ell_H(B),u_H(B)]$. Therefore the empirical distance to that interval divided by eight is a valid full-law lower bound. The maximum over the finite parity family remains sound.

### 8.4 Dominance

P82 is already sound. Taking

\[
L_{83}(B)=\max\{L_{82}(B),L_{\mathrm{par}}(B)\}
\]

immediately gives both soundness and

\[
L_{83}(B)\ge L_{82}(B).
\]

### 8.5 Exact arithmetic

The implementation uses rational endpoint transforms, finite endpoint products, affine combinations, empirical rational sums, interval distance, maxima, minima, and division by the integer eight. Rational inputs therefore remain exact throughout.

## 9. Strict improvement witness over P82

Fix the third observed channel to be exactly fair in both latent branches:

\[
q_{3,-}=q_{3,+}=\frac12,
\]

while prevalence and all remaining response parameters, including $q_{4,-}$ and $q_{4,+}$, remain free in $[0,1]$.

Define the empirical sixteen-cell law

\[
\boxed{
\widehat p_x
=
\begin{cases}
\frac18, & x_3=x_4,\\
0, & x_3\ne x_4.
\end{cases}
}
\]

There are eight equal-bit cells, so the masses sum to one.

For every P75 parameter vector in this box, the branchwise even-parity probability of views 3 and 4 is

\[
\begin{aligned}
P_s(X_3\oplus X_4=0)
&=
\frac{1+(1-2q_{3,s})(1-2q_{4,s})}{2}\\
&=
\frac{1+0\cdot(1-2q_{4,s})}{2}\\
&=\frac12.
\end{aligned}
\]

Therefore the latent mixture also satisfies

\[
q(X_3\oplus X_4=0)=\frac12
\]

for every admissible parameter vector.

Empirically,

\[
\widehat p(X_3\oplus X_4=0)=1.
\]

Since the parity event contains eight full observed cells,

\[
L_{\mathrm{par}}(B)
\ge
\frac{1-1/2}{8}
=\boxed{\frac1{16}}.
\]

The complete exact-rational audit of the predeclared P78-P82 families on this same box gives

\[
\boxed{L_{82}(B)=0.}
\]

This is not a floating numerical search result: the repository test evaluates the complete finite P82 family with `fractions.Fraction` arithmetic. Consequently,

\[
\boxed{
L_{83}(B)=\frac1{16}>0=L_{82}(B).
}
\]

The witness shows exactly what P83 adds. Separate cylinder and nested-residual interval tests can be individually compatible with the empirical law even while a simple dependence invariant implied by the model is violated.

## 10. Global branch-and-bound handoff

P83 can replace the P82 box lower bound inside the same exact-rational branch-and-bound framework. Active boxes continue to partition the complete nine-dimensional P75 parameter cube. The global lower bound is the minimum active P83 box bound.

For the upper direction, P83 deliberately reuses the already established certificates:

- every explicit P75 parameter vector gives a valid model-distance upper bound;
- the P78 mesh-width upper certificate remains valid because the underlying model-distance problem has not changed.

P83 does not claim that the new parity lower bound has an independently proved convergence rate.

## 11. P79 finite-data rejection handoff

Let $\overline\varepsilon_{79}$ be the certified rational upper envelope for the P77 cellwise sampling radius supplied by P79. Then

\[
\boxed{
L_{83}(\mathcal B)>\overline\varepsilon_{79}
\Longrightarrow
\mathcal C_n(\widehat p)\cap\mathcal M_{4,2}=\varnothing.
}
\]

This is a one-sided rejection statement. If the strict inequality does not hold, the result is inconclusive. It is not evidence that the P75 family is true.

## 12. Interpretation boundary

P83 proves an exact model-separation certificate for a declared latent-variable family. It establishes that some dependence information can be exposed more sharply by parity observables than by the earlier cylinder and nested-residual families.

It does **not** prove any of the following:

- that the P75 latent variable is a conscious state;
- that parity itself is a measure of consciousness;
- that failure of the P75 family implies nonphysical consciousness;
- that non-rejection validates P75;
- that quantum mechanics is required for the bridge;
- that the physical-to-experiential bridge has been solved.

The physical-to-experiential bridge remains open.
