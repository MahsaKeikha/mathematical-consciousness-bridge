# Proposition 48: Gap-dependent stopping complexity for sequential witness graphs

## Status

**Proved sufficient high-probability stopping-complexity theorem for the P47 sequential witness-graph procedure under an explicit preparation-level confidence-sequence envelope.**

P47 establishes validity under adaptive sampling, graph refinement, witness selection, pruning, and stopping. It deliberately leaves efficiency open. P48 provides the first quantitative stopping bound for that sequential layer.

The result is a sufficient upper bound, not a minimax lower bound and not an optimality theorem for adaptive experimental design.

P48 remains descriptor-relative and bridge-class-relative. It does not establish quantum incompleteness, a new physical dimension, or consciousness.

---

## 1. Problem

P47 shows that one may repeatedly inspect a finite declared witness graph

\[
G=(V,E)
\]

without invalidating the family-level certificate, provided every preparation-level stream is covered by a valid time-uniform confidence sequence.

That theorem answers

\[
\boxed{
\text{Is adaptive stopping statistically valid?}
}
\]

but not

\[
\boxed{
\text{How much data is sufficient before stopping must occur?}
}
\]

P48 answers the second question under an explicit shrinking-radius envelope.

---

## 2. Population regularity margin

For every declared edge

\[
e=\{i,j\}\in E,
\]

retain the P47 population regularity margin

\[
\boxed{
M_e=d_{Y,e}-L_e d_{Q,e},
}
\]

where

\[
d_{Y,e}=\|P_i-P_j\|_{\rm TV},
\qquad
 d_{Q,e}=D(\rho_i,\rho_j),
\qquad
L_e\ge0.
\]

Define its absolute sign gap

\[
\boxed{
g_e=|M_e|.
}
\]

The P48 finite stopping bound requires

\[
g_e>0
\]

for whichever sign conclusion must be reached.

If

\[
M_e=0,
\]

then arbitrarily accurate finite-data estimates can remain compatible with either sign. P48 therefore makes no finite sign-separation claim for a zero-gap edge.

---

## 3. Preparation-level confidence-sequence envelope

Suppose the P47 preparation-level target radii satisfy

\[
\boxed{
\varepsilon_i(n)
\le
A_{Y,i}
\sqrt{
\frac{\log(B_{Y,i}n^2)}{n}
},
}
\]

and the quantum radii satisfy

\[
\boxed{
r_i(n)
\le
A_{Q,i}
\sqrt{
\frac{\log(B_{Q,i}n^2)}{n}
}.
}
\]

Assume

\[
A_{Y,i},A_{Q,i}\ge0,
\qquad
B_{Y,i},B_{Q,i}\ge1.
\]

This envelope has the same qualitative structure generated by a summable local error schedule such as the P24/P47 Basel allocation

\[
\alpha_{i,n}
\propto
\frac{1}{n^2}
\]

combined with a fixed-sample exponential concentration inequality. The theorem itself only requires the displayed envelope; it does not require that particular construction.

---

## 4. Edge uncertainty proxy

At equal local endpoint count

\[
n,
\]

define the P47 uncertainty proxy

\[
U_e(n)
=
\varepsilon_i(n)+\varepsilon_j(n)
+
L_e\bigl(r_i(n)+r_j(n)\bigr).
\]

Define

\[
\boxed{
A_e
=
A_{Y,i}+A_{Y,j}
+
L_e(A_{Q,i}+A_{Q,j})
}
\]

and

\[
\boxed{
B_e
=
\max\{
B_{Y,i},B_{Y,j},B_{Q,i},B_{Q,j}
\}.
}
\]

Because every logarithmic factor is bounded by the largest one,

\[
\boxed{
U_e(n)
\le
A_e
\sqrt{
\frac{\log(B_e n^2)}{n}
}.
}
\]

This is the edge-level envelope used in the stopping theorem.

---

## 5. Deterministic margin perturbation lemma

Let

\[
[\underline M_e(n),\overline M_e(n)]
\]

be the P47 simultaneous interval evaluated when both endpoint target and quantum streams have at least \(n\) observations.

On the P47 good event, the empirical target distance obeys

\[
\widehat d_{Y,e}
\ge
 d_{Y,e}
-
\bigl(\varepsilon_i+\varepsilon_j\bigr),
\]

while the empirical quantum distance obeys

\[
\widehat d_{Q,e}
\le
 d_{Q,e}
+
\bigl(r_i+r_j\bigr).
\]

Substituting these into the P47 lower envelope gives

\[
\underline M_e(n)
\ge
M_e
-
2U_e(n).
\]

Similarly,

\[
\widehat d_{Y,e}
\le
 d_{Y,e}
+
\bigl(\varepsilon_i+\varepsilon_j\bigr),
\]

and

\[
\widehat d_{Q,e}
\ge
 d_{Q,e}
-
\bigl(r_i+r_j\bigr),
\]

so the P47 upper envelope satisfies

\[
\boxed{
\overline M_e(n)
\le
M_e
+
2U_e(n).
}
\]

Therefore

\[
\boxed{
M_e>0
\quad\text{and}\quad
U_e(n)<\frac{M_e}{2}
\Longrightarrow
\underline M_e(n)>0,
}
\]

and

\[
\boxed{
M_e<0
\quad\text{and}\quad
U_e(n)<\frac{|M_e|}{2}
\Longrightarrow
\overline M_e(n)<0.
}
\]

Thus the same uncertainty threshold certifies either sign.

## 6. Explicit inversion of the logarithmic confidence envelope

We now seek a finite local count \(N_e\) such that

\[
U_e(n)<\frac{g_e}{2}
\qquad
\forall n\ge N_e.
\]

It is sufficient to solve

\[
A_e
\sqrt{
\frac{\log(B_e n^2)}{n}
}
<
\frac{g_e}{2}.
\]

Define

\[
q_e
=
\left(
\frac{2A_e}{g_e}
\right)^2,
\]

and inflate it only to avoid a small-parameter edge case:

\[
\boxed{
Q_e=\max\{q_e,1\}.
}
\]

Let

\[
\boxed{
\Lambda_e
=
\log\left(
4Q_e\sqrt{B_e}
\right).
}
\]

Because \(Q_e\ge1\) and \(B_e\ge1\),

\[
\Lambda_e\ge\log4>1.
\]

Define the explicit sufficient local count

\[
\boxed{
N_e
=
\left\lceil
4Q_e\Lambda_e
\right\rceil.
}
\]

---

## 7. Proposition 48A: the explicit local-count bound is sufficient

Consider first the real value

\[
n_0=4Q_e\Lambda_e.
\]

Since

\[
\Lambda_e
=
\log(4Q_e\sqrt{B_e}),
\]

we have

\[
\log(B_e n_0^2)
=
2\bigl(\Lambda_e+\log\Lambda_e\bigr).
\]

Therefore

\[
\frac{q_e\log(B_e n_0^2)}{n_0}
\le
\frac{Q_e\,2(\Lambda_e+\log\Lambda_e)}
{4Q_e\Lambda_e}
=
\frac12
\left(
1+
\frac{\log\Lambda_e}{\Lambda_e}
\right).
\]

For every \(\Lambda_e>1\),

\[
\log\Lambda_e<\Lambda_e,
\]

so

\[
\boxed{
\frac{q_e\log(B_e n_0^2)}{n_0}<1.
}
\]

Equivalently,

\[
A_e
\sqrt{
\frac{\log(B_e n_0^2)}{n_0}
}
<
\frac{g_e}{2}.
\]

Moreover,

\[
f(n)=\frac{\log(B_e n^2)}{n}
\]

has derivative

\[
f'(n)
=
\frac{2-\log(B_e n^2)}{n^2}.
\]

At and beyond the stated threshold, \(B_e n^2\) is large enough that

\[
\log(B_e n^2)>2,
\]

so \(f(n)\) is decreasing. Hence every integer

\[
n\ge N_e
\]

also satisfies the desired inequality.

Thus

\[
\boxed{
U_e(n)<\frac{g_e}{2}
\qquad
\forall n\ge N_e.
}
\]

This proves the explicit P48 local-count bound.

## 8. Round-robin active-graph policy

P48 now specifies one concrete acquisition policy whose stopping complexity can be proved.

At sequential epoch \(k\):

1. every currently active preparation receives one additional target sample;
2. every currently active preparation receives one additional quantum/tomography sample;
3. all P47 edge intervals are recomputed;
4. every edge with
   \[
   \overline M_e(k)<0
   \]
   is safely eliminated;
5. any vertex with no remaining active incident edge can be pruned;
6. if some active edge satisfies
   \[
   \underline M_e(k)>0,
   \]
   the experiment stops with a positive witness;
7. if all declared edges have been eliminated, the experiment stops with a no-positive-edge certificate.

The policy is intentionally simple. Its purpose is to establish a transparent finite stopping bound. P45/P46 priority rules can later improve efficiency without changing the P47 validity statement.

---

## 9. Positive edges cannot be pruned on the simultaneous event

Suppose

\[
M_e>0.
\]

On the P47 good event,

\[
M_e
\le
\overline M_e(k)
\]

at every epoch.

Therefore

\[
\overline M_e(k)>0
\]

for every epoch before positive certification.

The edge can never satisfy the negative-elimination rule

\[
\overline M_e(k)<0.
\]

Hence neither of its endpoints can be pruned solely because all incident active edges were certified negative while that positive edge remains present.

Consequently, both endpoints of every truly positive declared edge continue to receive samples under the active round-robin policy.

This observation is what turns the local-count bound into a sequential epoch bound.

---

## 10. Proposition 48B: finite stopping bound when a positive witness exists

Let

\[
E_+
=
\{e\in E:M_e>0\}.
\]

Assume

\[
E_+\ne\varnothing.
\]

For each positive edge, P48A supplies a sufficient local count \(N_e\).

Define

\[
\boxed{
K_+
=
\min_{e\in E_+}N_e.
}
\]

Choose an edge

\[
e_*\in\arg\min_{e\in E_+}N_e.
\]

By the no-pruning result, both endpoints of \(e_*\) remain active through epoch \(K_+\). They therefore receive at least \(K_+\) samples in both modalities.

P48A gives

\[
U_{e_*}(K_+)
<
\frac{M_{e_*}}{2}.
\]

The deterministic margin lemma then gives

\[
\boxed{
\underline M_{e_*}(K_+)>0.
}
\]

Therefore the sequential procedure must stop no later than epoch

\[
\boxed{
K_+
=
\min_{e:M_e>0}N_e.
}
\]

on the P47 simultaneous good event.

Since P47 gives

\[
\Pr(\mathcal E_*)
\ge
1-\alpha_Y-\alpha_Q,
\]

the stopping statement inherits the same probability guarantee:

\[
\boxed{
\Pr(\tau\le K_+)
\ge
1-\alpha_Y-\alpha_Q.
}
\]

Here \(\tau\) is the positive-witness stopping epoch of the declared procedure.

---

## 11. Proposition 48C: finite stopping bound when every edge is negative

Now suppose

\[
\boxed{
M_e<0
\qquad
\forall e\in E.
}
\]

For every edge, define its P48 count \(N_e\), and let

\[
\boxed{
K_-
=
\max_{e\in E}N_e.
}
\]

At epoch \(N_e\), P48A gives

\[
U_e(N_e)
<
\frac{|M_e|}{2}.
\]

Hence the deterministic margin lemma gives

\[
\overline M_e(N_e)<0.
\]

So edge \(e\) must have been eliminated by that epoch.

By epoch \(K_-\), every declared edge has therefore been eliminated. The algorithm returns the finite-family conclusion

\[
\boxed{
M_e<0
\qquad
\forall e\in E
}
\]

on the P47 simultaneous event.

Thus

\[
\boxed{
\Pr(\tau_0\le K_-)
\ge
1-\alpha_Y-\alpha_Q,
}
\]

where \(\tau_0\) is the no-positive-edge stopping epoch.

## 12. Zero-gap boundary

Suppose there is no positive edge but at least one edge satisfies

\[
M_e=0.
\]

For that edge,

\[
g_e=0.
\]

No finite value of \(n\) can satisfy the generic requirement

\[
U_e(n)<\frac{g_e}{2}=0
\]

unless the uncertainty is already exactly zero.

Therefore P48 intentionally returns

\[
\boxed{
\text{no finite sign-gap bound}
}
\]

for the all-nonpositive family when any unresolved population margin is exactly zero.

This is not a weakness of the proof. It is the mathematically correct boundary between finite sign separation and a population equality case.

## 13. Measurement-cost bound

Let

\[
c_i>0
\]

be the declared cost of one full epoch of preparation \(i\), including whichever target and quantum measurements are required by the protocol.

If every vertex remained active for \(K\) epochs, the total acquisition cost would be

\[
\boxed{
C_{\rm full}(K)
=
K\sum_{i\in V}c_i.
}
\]

Under unit cost for each of two modalities,

\[
c_i=2,
\]

so

\[
\boxed{
C_{\rm full}(K)=2|V|K.
}
\]

Now let

\[
V_k\subseteq V
\]

be the active vertex set at epoch \(k\). The realized safely pruned cost is

\[
\boxed{
C_{\rm active}(K)
=
\sum_{k=1}^{K}
\sum_{i\in V_k}c_i.
}
\]

Since

\[
V_k\subseteq V,
\]

we immediately obtain

\[
\boxed{
C_{\rm active}(K)
\le
C_{\rm full}(K).
}
\]

The inequality is strict whenever at least one positive-cost preparation is pruned before the final epoch.

Therefore P47 safe pruning can only improve the realized cost relative to the P48 full-family upper bound.

## 14. Gap scaling

Ignoring only logarithmic factors, the local-count bound has the dominant scaling

\[
Q_e
\sim
\left(
\frac{A_e}{g_e}
\right)^2.
\]

Hence

\[
\boxed{
N_e
=
O\left(
\frac{A_e^2}{g_e^2}
\log\left[
\frac{A_e^2\sqrt{B_e}}{g_e^2}
\right]
\right).
}
\]

This makes the statistical geometry explicit.

Large positive or negative population margins are easier to classify.

Small margins are intrinsically harder because the confidence interval must contract much further before its sign is determined.

The regularity constant \(L_e\) also enters the edge amplitude through

\[
A_e
=
A_{Y,i}+A_{Y,j}
+
L_e(A_{Q,i}+A_{Q,j}),
\]

so a more permissive bridge regularity class can increase the measurement precision required for certification.

## 15. Relation to P42 and P43

P42 gave an explicit fixed-pair finite-sample theorem for a declared informationally complete quantum measurement and categorical target model.

P43 optimized the split between quantum and target resources for one fixed pair.

P48 is different in three ways.

First, it operates inside a finite witness graph rather than one fixed pair.

Second, it is sequential and inherits P47 repeated-look validity.

Third, its stopping time can be data-dependent, and safe pruning changes the active graph during acquisition.

The logical progression is therefore

\[
\boxed{
\text{P42 fixed-pair sample complexity}
\to
\text{P43 fixed-pair optimal allocation}
\to
\text{P44-P46 finite-family graph design}
\to
\text{P47 valid sequential refinement}
\to
\text{P48 explicit sequential stopping complexity}.
}
\]

---

## 16. Relation to P45 shared allocation

P45 can still reduce practical cost because it allocates precision according to shared incidence constraints instead of sampling every active preparation equally.

P48 does not claim that active round robin is optimal.

Instead, P48 provides a rigorous reference upper bound against which more aggressive adaptive policies can be compared.

Any future policy that claims an efficiency improvement should preserve the P47 validity conditions and should report whether its realized or expected cost improves upon

\[
C_{\rm full}(K_+)
\]

in the positive case or

\[
C_{\rm full}(K_-)
\]

in the all-negative case.

---

## 17. Relation to P46 discrete graph selection

P46 addresses which preparations should be included under a hard acquisition budget.

P48 assumes a finite declared family has already been admitted to the sequential search.

A P46-selected initial subgraph can therefore serve as the starting graph for P48, provided that the family-level P47 error accounting covers every edge that may later participate in certification.

P48 does not remove P46's NP-hardness result and does not treat a graph-selection heuristic as a statistical theorem.

---

## 18. What P48 proves

Under the stated preparation-level confidence-sequence envelope and the P47 simultaneous event, P48 proves:

1. a deterministic sufficient uncertainty threshold for the sign of one population regularity margin;
2. an explicit closed-form local sample count \(N_e\) that reaches that threshold;
3. a finite stopping-epoch bound when at least one positive-margin witness exists;
4. a finite stopping-epoch bound when every declared margin is strictly negative;
5. the absence of a generic finite sign-separation bound at exactly zero population margin;
6. a full-family measurement-cost upper bound and a proof that P47 safe pruning cannot increase realized acquisition cost.

---

## 19. What P48 does not prove

P48 does not prove that the displayed sufficient bound is minimax optimal.

It does not prove that round-robin sampling is the most efficient sequential policy.

It does not prove that the preparation-level confidence envelope is tight.

It does not repair model misspecification, nonstationarity, calibration failure, or target-definition error.

It does not show that the quantum descriptor is ontologically complete.

It does not show that quantum mechanics is incomplete.

It does not show that a positive margin is consciousness.

It does not show that consciousness constitutes an additional spacetime or physical dimension.

The valid scientific conclusion remains a finite-data statement about a declared regular physical-to-target bridge class.

## 21. Next theorem target

P48 gives a conservative round-robin upper bound. The next open mathematical problem is to quantify the value of adaptive prioritization.

A natural P49 target is an **instance-dependent adaptive sampling theorem** comparing a P45-informed uncertainty-priority policy against the P48 full-family reference cost.

The desired statement would separate

\[
\boxed{
\text{validity}
\quad+
\text{finite stopping}
\quad+
\text{adaptive efficiency gain}.
}
\]

A serious P49 theorem should either derive an oracle inequality or prove a regret/sample-overhead bound under an explicit fairness condition. It should not call a heuristic optimal without such a proof.
