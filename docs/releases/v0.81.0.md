## P81 contribution

P81 extends the P75-P80 adequacy and certification sequence. For each parameter box in the declared four-view binary latent model, it computes exact ranges for projected events such as marginals and higher-order cylinder events. If an empirical event probability lies outside the corresponding model event range, the event mismatch yields a lower bound on the full-law L-infinity distance through the event-size Lipschitz relation.

The combined P81 box certificate is the maximum of:

1. the P80 probability-simplex-coupled lower bound, and
2. the P81 projection-event lower bound.

Consequently, the P81 certificate is never weaker than P80 on the same parameter box and can be strictly stronger when the empirical full law lies inside the P80 interval-simplex relaxation but violates a projected-event constraint.
