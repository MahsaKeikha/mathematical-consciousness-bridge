# Research Architecture

## Layer 1: Physical realization

A physical description should specify:

\[
p=(\mathcal X,\mathcal D,\mathcal I,\mathcal O)
\]

with state space, dynamics, intervention structure, and observable map.

## Layer 2: Certified subsystem

When applicable, Spatiotemporal Observer Mathematics supplies a candidate world-tube

\[
\mathcal W=(S_0,\ldots,S_{T-1})
\]

with recovery and uncertainty statements.

## Layer 3: Physical equivalence

Define which changes of representation leave the physical system unchanged for the purposes of the bridge.

## Layer 4: Experiential formalization

Define the mathematical structure assigned to experiential states without yet assuming a particular physical bridge.

## Layer 5: Bridge

Define

\[
\mathcal B:\mathcal P/{\sim_P}\to\mathcal E/{\sim_E}
\]

when single-valuedness is justified, or retain a relation when it is not.

## Layer 6: Empirical interface

Define the experiments and observable distributions that allow competing bridge hypotheses to be compared.

## Layer 7: Conditional theorem

Only after Layers 1-6 are explicit should the project state a consciousness theorem.

This architecture prevents an ambiguity common in consciousness mathematics: confusing a proof internal to a formalism with evidence that the formalism's bridge to experience is correct.
