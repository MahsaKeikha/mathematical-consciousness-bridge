# Visual research gateway

This top-level `figures/` directory is the reader-facing entry point for the visual side of the Mathematical Consciousness Bridge project.

The complete canonical figure archive lives in [`docs/figures/`](../docs/figures/). This folder exists so a first-time visitor opening the repository from GitHub can immediately understand where the current figures are, which figures are generated by code, which are theorem diagrams, and how the visual record connects to the proposition sequence.

## Reproduce the generated figures

From the repository root:

```bash
python scripts/generate_all_figures.py
```

Validate the existing figure tree without regenerating outputs:

```bash
python scripts/generate_all_figures.py --validate-only
```

The canonical generators are:

```text
scripts/generate_quantitative_atlas.py
scripts/generate_quantum_foundations_atlas.py
```

For the full environment setup and command sequence, see [`docs/reproducibility.md`](../docs/reproducibility.md).

## Important provenance distinction

A figure in this repository is not automatically empirical evidence.

The computational atlases are generated from declared mathematical or simulation procedures. The theorem figures are explanatory publication diagrams. Their scientific status comes from the associated assumptions, derivations, tests, provenance records, and evidence class, not from the fact that they are visual.

The project keeps these categories explicit so readers can distinguish:

1. standard mathematics and established physical theory;
2. repository-original theorem or computation;
3. synthetic or model-based illustration;
4. external empirical evidence; and
5. open hypotheses or research targets.
